## 左上から開き、人と作品を探せるようにする

Tukuriumの左上にあるツクリウムボタンから、一つのメニューウィンドウを開く。中で五つの画面を切り替え、誰がどこにいるかを見たり、使いたい作品を探したりする。セッションに参加したまま使え、閉じると元の空間や制作へ戻る。

2Dクライアントは追加しない。通常の画面内に固定する表示と、3D空間に置く表示は、既存の制作パネルと同じ操作で切り替える。

| 画面 | 見るもの | 主な操作 |
| --- | --- | --- |
| ホーム | フレンドがいる場所、所持アイテム、マーケットの新着 | 各画面の対象を開く。参加する、取り出す |
| フレンド | 相手の状態、ひとこと、参加中のセッション | 相手の場所を見る。参加、声かけ、招待へ進む |
| セッション | 開いている集まり、持ち主、参加者、自分の現在地 | 検索、詳細、参加、戻る、移動、作成 |
| アイテム | 自分が所持する作品と、その詳細 | 検索、詳細、参加中の場所へ取り出す |
| マーケット | 公開作品、作者、説明、所持しているか | 検索、詳細、入手。所持済みなら取り出す |

制作やプログラミングの詳細は既存の計画で扱う。ここでは「集まりを選ぶ」「作品を探す」「自分の場所へ持ち込む」をつなぐ。

## 一つのウィンドウの中で切り替える

```text
ツクリウム                 参加中: みんなの作業部屋     [固定] [閉じる]
─────────────────────────────────────────────────────────────────
ホーム          │ 画面ごとの検索・絞り込み
フレンド        │
セッション      │ 一覧・カード                 │ 選んだ対象の詳細
アイテム        │                              │
マーケット      │                              │ 参加する／入手する
                │                              │ 取り出す
```

これは情報配置の概略。会話内で確認した拡張モック `tukurium-hub.html` を画面の参考にする。表示中の人物・作品・セッション・価格は架空データであり、本体の初期データや保存仕様ではない。

- 初回はホームを開く。閉じて開き直したときは、最後に見ていた画面・検索語・選択・一覧の位置へ戻る。
- 上部に現在の参加先を残す。未参加なら「セッション未参加」と表示する。
- 開閉と画面切り替えだけでは、退出、再参加、制作の終了を起こさない。
- ウィンドウは移動・サイズ変更でき、画面内への固定と3D空間への配置を切り替えられる。見失ったときは左上から呼び戻せる。
- 小さいウィンドウでは詳細を一覧の代わりに表示し、「一覧に戻る」で元の検索と位置へ戻す。横幅が足りなくても主要操作を隠さない。
- キーボードで一覧・詳細・ボタンへ移動できる。メニュー操作中のキー入力を、移動やアイテム操作へ流さない。

メニューは本人だけが使う画面とする。検索やフレンドの情報を、他の人に見せる制作パネルの要約へ含めない。実装上の状態保持とパネルへの接続は[実装計画](main-menu-implementation.md#3-メニューの状態をワークスペースから独立させる)にまとめる。

## ホームで、次に行く場所を見つける

フレンドがいるセッションを先に見せ、所持アイテムとマーケットの新着も並べる。ホーム専用の別データを作らず、各画面と同じ対象を表示する。

セッションのカードから参加先を確認し、所持アイテムから取り出しへ進める。マーケットのカードは作品の詳細を開く。フレンドや所持品がまだなければ、セッションを探す・マーケットを見る入口を出す。

## フレンドから、相手の場所へ進む

相手の名前、状態、ひとこと、参加先を一覧にする。状態はモックの「参加 OK」「声かけて」「取り込み中」「オフライン」を候補にする。色だけで区別せず、文字を添える。

相手がいるセッションを選ぶと、参加者と現在地を確かめて参加できる。「行ってもいい？」や招待は、返事待ち・承認・辞退・期限切れを表示する案とする。招待を受けただけで勝手に移動しない。

フレンドの追加・解除も必要になる。相互フォローで成立させるか、申請と承認で成立させるか、状態と招待を最初にどこまで実装するかは、[実装計画の判断項目](main-menu-implementation.md#8-実装前に確定する残りの判断)で決める。

## セッションで、誰がいるかを見て参加する

一覧はセッション名、持ち主、人数、表示できる参加者を見せる。選ぶと詳細に参加者を表示する。自分が参加している場所は、一覧と上部の両方で分かるようにする。

| 自分の状態 | 操作と結果 |
| --- | --- |
| 未参加 | 「参加する」で選んだセッションに入る |
| 選んだ場所に参加中 | 「このセッションに戻る」でメニューを閉じる。再参加しない |
| 別の場所に参加中 | 現在地と移動先を示し、必要な確認を経て移動する |
| 持ち主として参加中 | 退出でセッションが閉じる条件を、一般参加者と区別して示す |

一覧取得後に対象が閉じた場合は、その場で知らせて一覧を更新する。読み込み中の人数をゼロと表示しない。公開できる参加者情報の範囲と、参加中の一覧更新はサーバー側の設計と合わせる。

## マーケットで入手し、アイテムから取り出す

「入手」は自分の所持一覧へ登録する操作、「取り出す」は参加中のセッションへ配置する操作として分ける。入手しただけでは空間に物を出さない。所持一覧は、ゲーム中に物を拾って入れるバッグや、制作に組み込むライブラリとも区別する。

### マーケット

名前や作者から公開アイテムを探し、カードから見た目・名前・作者・所持状態を確かめる。詳細には説明、使い方、利用する版、使える範囲を表示する案とする。画像や説明が未設定でも代わりの表示で選べるようにする。

未所持なら「入手する」、所持済みなら「取り出す」を表示する。初期の実装案は無料の入手を対象とし、決済は含めない。カテゴリの持ち方や作者が設定する画像は、保存する情報が決まってからつなぐ。

### アイテム

所持している作品を検索し、カードや詳細から「取り出す」を実行する。何をどこへ出すかが操作前に分かり、成功したら作品名と配置先を知らせる。入手した版と、更新の扱いは実装前に確定する。

未参加なら「セッションを選ぶ」へ進み、参加後も検索と選択を保つ。その後、本人が改めて「取り出す」を押す。自動で参加・配置しない。

処理中は連打による二重配置を防ぐ。完了後はもう一個取り出せる。利用できない作品やリリースがない作品は理由を表示し、失敗しても検索結果と選択を失わない。

## 画面をまたぐ操作で確かめる

| 利用場面 | 確かめる流れ |
| --- | --- |
| フレンドに合流する | ホーム → フレンドがいる場所 → 参加者と参加先の確認 → 参加 |
| 開いている集まりを探す | セッション → 検索 → 参加者を見る → 参加／移動 |
| 新しい作品を使う | マーケット → 検索・詳細 → 入手 → アイテム → 取り出す |
| 手持ちの作品を持ち込む | アイテム → 検索 → 現在のセッションへ取り出す |
| 未参加で作品を先に探す | マーケット → 入手 → セッション選択 → 検索・選択を保って取り出す |
| 作業へ戻る | メニューを閉じる → 現在地と編集中の状態を保って制作を続ける |

空一覧、検索結果なし、読み込み中、取得失敗、オフライン、対象が使えなくなった状態を区別する。画面モックで確認した見た目に加え、実装ではこれらの状態も確認する。

具体的な担当箇所、追加データ、実装順、完了条件は[メインメニュー実装計画](main-menu-implementation.md)で管理する。作品・リリース・権限の基盤は[UGC計画のU6](ugc-api-library-permissions.md#u6-ユーザー間-library)へ接続する。
