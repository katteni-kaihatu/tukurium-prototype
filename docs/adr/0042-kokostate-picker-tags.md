# ADR 0042：KokoState を付けるウィンドウ（検索・件数付きタグ・カード）

- 状態：採用・実装済み（2026-11-06）
- 関連：ADR 0011（KokoState の役割）、ADR 0040（Inspector）

## 背景

KokoState を付ける画面は、Inspector の中の検索欄と縦の一覧だった。Built-in・自作・ライブラリの KokoState が増えると、探しにくい。利用者から、アイテムを探すサイトの UI（検索欄・件数付きのタグ・カード）を参考にするよう頼まれた。

## 決定（利用者と決めたこと）

- 「＋ Add KokoState」を押すと、「KokoState を付ける」を開く。最初は別のウィンドウだったが、ADR 0044 で Inspector の付属パネルに替えた（付けても閉じず、いま選んでいる Entity に付ける）。
- 上に検索欄を置く。名前・フィールド名・ライブラリの別名に当てる。
- 検索欄の下に**件数付きのタグ**を 2 組並べ、押して絞り込む。
  - 出どころ：このプロジェクト・ライブラリ（`@別名`）・Built-in
  - 役割：配置・見た目・物理・操作・音・文字・遊び・役割なし
  - 同じ組の中で選んだタグは、どれかに合えば出す。組をまたぐと、両方に合うものだけを出す。
  - 件数は、検索ともう一方の組の選択を当てたあとの数。
- 結果は、**表**（既定）と**カード**を切り替えて出す（Resources と同じ切り替えの形）。どちらも名前・出どころ・役割・フィールドの数を出す。選んだ形は人ごとにブラウザに覚える。並びは、自作 → ライブラリ → Built-in の順にする。
- 見た目は作りだけを参考にし、色や角の丸みは今の Tukurium に合わせる。

## 役割

- `KokoStateDef.role`（任意）に持つ。一覧は repo-model の `KOKO_ROLES`。
- Built-in には最初から役割を付けた。自作の KokoState は、詳細の「役割」で選べる。
- 役割は絞り込みのためだけに使い、実行には関わらない。

## 結果

- 絞り込みの決まりは `apps/client/src/workspace/kokoCatalog.ts` にまとめ、単体テストで守る。
- E2E（m1）の「KokoState を付ける」手順は、新しいウィンドウを使うように直した。
