# ADR 0030：ワークスペースの入口だけ旧表示に戻す

- 状態: 採用・実装済み（2026-11-05）
- 関連: [ADR 0029](0029-independent-tool-windows.md)、[ADR 0028](0028-session-and-optional-workspace.md)
- 補足: [ADR 0067](0067-close-workspace.md) で、ここでの「ワークスペースを閉じる」は「出る」と「閉じる」に分かれた

## 決定

上のバーのワークスペースだけは、以前の「現在のワークスペース名と数が見える切り替え表示」に戻す。開いていなければ「開いていません」と表示する。クリックすると、そのセッションで開けるワークスペースの一覧と作成操作を出す。編集中の画面へ戻る操作と、ワークスペースを閉じる操作もここに置く。

ホーム・フレンド・セッション・アイテム・マーケット・プロジェクトの独立ウィンドウは維持する。ワークスペースの切り替えで、それらのウィンドウは閉じない。セッションに参加しただけでは編集を始めない。

切り替えの一覧は Esc または外側のクリックで閉じる。その操作で他のウィンドウを閉じない。
