# ADR 0047：マーケットの作品は、詳細ページで開く

- 状態: 採用・実装済み
- 関連：ADR 0024（マーケットの検索）、ADR 0034（横の詳細欄。マーケットでは置き換える）

## 理由

マーケットは検索の一覧と、作者と最新の版だけの短い欄だった。バージョンの並びと、その版を出したときのコメントを見る場所がなく、自分の作品へ戻る入口もなかった。作品から、公開されているプロジェクトへ辿ることもできなかった。

## 決定

- マーケットで作品を選ぶと、一覧に代わって詳細を出す。戻ると、開いていたタブの一覧に戻る。
- バージョンは新しいものから並べる。コメントは、その版の保存メッセージを出す。リリース専用のコメントは持たない。
- プロジェクトが公開のときだけ、作品の詳細からそのプロジェクトを開ける。非公開のプロジェクトは、作品が見えても参照を出さない。
- 「自分の作品」タブは、ログインしている人の作品（アイテム・ワールド・ライブラリ）を出す。さがすタブは、これまでどおりアイテムだけ。
- 入手できるのはアイテムだけ。ワールドとライブラリの詳細には入手を出さない。
- 所持アイテムの横の詳細欄（ADR 0034）はそのまま残す。
