# ADR 0069：セッションに出ているアイテムは、アイテム一覧に出す

- 状態: 置き換え（2026-11-12）。一覧の場所は [ADR 0070](0070-sidebar-session-items.md)
- 関連: [ADR 0024](0024-owned-items-and-placement.md)、[ADR 0034](0034-owned-item-tags-and-browsing.md)、[ADR 0062](0062-session-tag-and-sidebar.md)

## 理由

所持アイテムからセッションへ取り出しても、出したことは左の欄の件数にしか残らない。どのカードが今出ているのか、一覧を見ただけでは分からない。

取り出したアイテムは、セッションのホストが実行する。ホストの画面で Simulation に配置が足され、ほかの参加者にはその状態が配られる。

## 決定

セッションに出ているアイテム（ワールドは含めない）は、アイテム一覧に出す。左の欄には個々のアイテムを並べない。

- いま一覧に見えている所持品は、そのカードに「出しています」と個数を出す。同じ版を複数出しているときは、カードの「外す」で 1 個だけ外す。
- 詳細には、誰が出したかを並べ、外せるものにはそれぞれ「外す」を置く。外せるのは、セッションの持ち主と、その配置を出した人。
- 絞り込みでカードが隠れている所持品と、ワークスペースから出したアイテムは、一覧の上に「セッションに出ている」として残す。
- 「取り出す」は、すでに出していても別の 1 個を足せる。

## 確認

銃のリリースを所持一覧から取り出すと、ホストの実行に Shoot が載り、時間が進む。カードに「出しています」が出て、「外す」で配置が消える。
