# ADR 0044：付属パネル（本体のパネルにくっつく、たたむだけのパネル）

- 状態：採用・実装済み（2026-11-06）
- 関連：ADR 0003（2D / 3D のパネル）、ADR 0042（KokoState を付ける）

## 背景

KokoState を付けるのは、Inspector であれこれ触りながら続けて行うことが多い。別のウィンドウだと、付けるたびに閉じ、開き直し、置き場所を合わせる手間がかかる。Resources で選んだものの詳細も同じで、Resources の横に出ていてほしい。

## 決定（利用者と決めたこと）

- 新しい種類のパネル「**付属パネル**」を作る。本体のパネルの横にくっつき、本体と一緒に動く。2D（画面に固定）でも 3D（空間に置く）でも完全に追従する。
  - ピンは付けない（本体に従うので要らない）。× もなく、**開く・たたむ**だけ。
  - たたむと、本体の横に縦書きのつまみが残る。押すと開く。
  - 高さは本体に合わせる（低すぎるときは広げる）。
  - いつも本体の右に出す。画面の右端に置いた Resources などでは、画面からはみ出してもよい。
- Inspector の付属パネル「**KokoState を付ける**」
  - 付ける先は、いま選んでいる Entity。選び直すと付ける先も替わる。
  - 付けても閉じない。続けて付けられる。
  - 「＋ Add KokoState」を押しても開く。編集できるとき（編集の権限があり、Edit mode のとき）だけ出す。
- Resources の付属パネル「**リソースの詳細**」
  - Resources で選んだときだけ、ここに出す。
  - ほかの場所（エラーの一覧、詳細の中の System など）から開く詳細は、これまでどおりの「詳細」パネルに出す。
  - 中身で削除したときは、この付属パネルの中身を空にする（ふつうの詳細パネルは閉じない）。

- 保存・履歴の付属パネル「**差分の中身**」
  - これまで右の欄に出していた差分の中身を、ここに出す。差分を選ぶと開く。
  - 本体は、保存は 1 列、履歴は「履歴」と「詳細」の 2 列になり、そのぶん幅を狭くした。

## 作り

- `PanelSpec.drawer`（`PanelLayer.tsx`）。付属パネルは本体の入れ物（host）の中に描く。そのため、2D の位置も、3D の CSS3DObject の動きも本体と同じになる。
- 状態を本体のパネルに置いたまま中身だけ付属パネルへ出すときは、付属パネルに受け皿（`DrawerSlot`）を置き、本体から `InDrawer` で portal する（`panels/drawerSlot.tsx`）。
- 3D では、WebGL に開ける穴（occluder）を、付属パネルを含めた範囲に広げ、その中心へずらす（`PanelSpace.fitOccluder`）。本体の位置は動かさない。
- 3D のパネルの中でフォーカスが移ると、ブラウザが空間の入れ物を勝手にスクロールし、パネルがずれて見えた。入れ物は常にスクロールしないようにした（`SessionEngine`）。
