# ADR 0034：作者の公開タグでアイテムを探す

- 状態: 採用・実装済み（2026-11-05）

## 理由

Tonarium のアイテム一覧は名前と一緒に分類を示し、詳細画面から使い方を確認できる。ツクリウムでも作者が分類を伝え、利用者が名前だけに頼らずアイテムを探せるようにする。

## 決定

タグは作者が作品の公開時に付ける。作品の情報としてサーバーに保存し、公開後も作者だけが変更できる。マーケットと所持アイテムの両方に表示する。自分用のローカルタグは公開タグとして扱わない。

タグは 1 作品につき 12 個まで、1 個につき 24 文字までとする。前後の空白は除き、全角・半角や大文字・小文字だけが異なるタグは重複させない。タグのない既存作品もそのまま使える。

名前・作者・タグをまとめて検索し、複数のタグを組み合わせたときは、指定したタグがすべて付いている作品を返す。所持品ではお気に入り、利用可否も組み合わせて絞り込める。並べ替えとカード／リストの表示切り替えは維持する。

詳細欄は一覧の横に常に確保し、未選択なら選択を促すプレースホルダーを表示する。一覧を残して詳細を切り替えるため、「一覧に戻る」は置かない。所持している版、入手日、取り出す操作、公開タグをまとめ、作者本人にはタグを編集するボタンを表示する。狭いウィンドウでは詳細を一覧の前に表示する。

公開タグは作品全体の情報とし、タグの編集でリリース内容や所持している版は変えない。お気に入りと表示方法だけを、アカウント別にブラウザへ保存する。

## API

`POST /api/works` と `PATCH /api/works/:id` で、任意の `tags: string[]` を受け取る。省略された作成時は空配列、更新時は現在のタグを保つ。空配列を指定するとタグをすべて外す。

`GET /api/market` の `q` はタグも検索する。`tag` クエリはタグとの完全一致で絞り込み、複数指定できる。絞り込みはページ分割より先に行う。検索結果と所持一覧には作品の現在のタグを返す。作品の保存領域は既存の JSON を使い、データベースの列追加は行わない。
