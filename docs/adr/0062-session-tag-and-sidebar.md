# ADR 0062：上のバーをなくし、セッションの情報を左上の札と左の欄に移す

- 状態: 採用・実装済み（2026-11-10）
- 変更: [ADR 0031](0031-global-navigation-and-session-bar.md) の上のバー
- 継続: [ADR 0030](0030-workspace-switcher-display.md) のワークスペース表示、[ADR 0029](0029-independent-tool-windows.md) の独立したウィンドウ、[ADR 0061](0061-global-navigation-menu.md) のグローバルメニュー

## 背景

UI をトナリウムに寄せる段階 2。統合案には上のバーがない。セッションの名前は左上の小さな札に置き、セッション内の人・作業・物は左の欄に縦に並べる。

## 決定

1. 上のバーをなくす。ホームへの入口はグローバルメニューの「ホーム」、退出はグローバルメニューの下に置く（ADR 0061）。
2. 左上の札に、今いるセッションの名前、ワールドの名前、人数と接続の状態を出す。未参加なら「セッション未参加」と接続の状態だけを出す。札にある歯車（セッションの設定）は、ボタンだけ置く。
3. セッション内では、札の下に左の欄を置く。中身は上から次の 3 つ。
   - プレイヤー：参加者と「あなた」「持ち主」の印
   - ワークスペース：これまでの切り替え（名前と数が見える表示と、開く・作るの一覧）
   - アイテム：「セッション」（出ている作品）と「バッグ」を開く。画面共有とウィンドウの表示の切り替え（カンタン・フリー）は、ボタンだけ置く
4. 左の欄はたためる。たたむと、開くボタン・参加者の頭文字・人数だけの列になる。制作を始めたらたたみ、制作をやめたら開く。幅 760px 以下の画面では、たたんで始める。
5. ウィンドウの初期位置と呼び戻し先は、グローバルメニュー・札・左の欄の端から測る。それぞれの大きさが変わったら測り直す。

## この記録で決めないこと

参加者との距離（すぐそば・声が届く）での分け方は、通話の仕組みがないので入れない。右の欄（通知・チャット・通話の操作）は次の段階で決める。
