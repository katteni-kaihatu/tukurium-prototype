# ADR 0052：ほかのプロジェクトから、開いているワークスペースへ取り込む

- 状態: 採用・実装済み
- 関連：ADR 0010（論理パス）、ADR 0015（ライブラリ・依存）、ADR 0044（付属パネル）

## 理由

ほかのプロジェクトの中身を使うには、プロジェクトの画面から「抽出」して新しいプロジェクトにするか、編集用のデータがないプロジェクトへ取り込むしかなかった。編集しているワークスペースへ、要るものだけを持ってきたい。

## 決定

- Resources の「New」に「ほかのプロジェクトから」を置き、新しいパネル「ほかのプロジェクトから取り込む」を開く。
- パネルでは、取り込み元のプロジェクト（自分のもの・公開されているもの）を選び、その中のアウトプット・KokoState・Script・Material・素材を選ぶ。右には、選んだものが使うもの（Entity の KokoState・マテリアル・素材、System の KokoState、ライブラリ）を「一緒に取り込むもの」としてまとめて出す。右下の「インポート」で取り込む。
- 取り込みは、抽出と同じ `extractInto` で今の中身に足した結果を作り、増えた分だけを編集中のデータへ足す（`ProjectDoc.mergeAdditions`。いまあるものは書き換えない）。共同編集の相手にも一度に届く。保存は今までどおり保存パネルから。
- 取り込み元の中身は、抽出と同じく、フォークできる人にだけ渡す（`GET /api/repos/:id/import-source`。見るだけの人には渡さない）。取り込むのは、取り込み元のいまの最新のコミット。
- 由来（provenance）に、元のリポジトリ・コミット・取り出したものの名前に加えて、取り出したリソースの元の論理パス（`paths`）を残す。
