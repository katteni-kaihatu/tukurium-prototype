# ADR 0035：フレンドに見せるステータスをプレビューして設定する

- 状態: 採用・実装済み（2026-11-05）
- 関連: [ADR 0025](0025-friend-requests-and-presence.md)

## 理由

Tonarium のステータス画面を参考に、状態の意味を読みながら選び、フレンドからどう見えるか確かめて保存できるようにする。

## 決定

フレンド画面の「ステータスを変更」から専用のダイアログを開く。「参加 OK」「オンライン」「声かけて」「取り込み中」を色付きの選択肢で並べ、ひとことと一緒にプレビューする。新規ユーザーの初期値は「オンライン」にする。既存の設定は変えない。

ひとことの入力欄は32文字までとし、文字数を表示する。従来のAPIは120文字まで受け付けていたため、保存済みの長いひとことは切り捨てず表示する。32文字を超える場合は保存ボタンを無効にし、短くしてから保存するよう案内する。APIの上限は互換性のため120文字を維持する。

「設定する」で保存するまではフレンドへの表示を変えない。キャンセル、閉じるボタン、Escで変更を破棄する。Escで背後のフレンドウィンドウを閉じない。保存に失敗したときは入力を残して再試行できるようにする。

状態は交流の意向を伝える表示であり、参加権限や招待の送受信は変えない。「行ってもいい？」の参加確認、通知停止、グループへの共有は今回追加しない。実際の接続が切れたフレンドは、選択した状態にかかわらず「オフライン」と表示する。

変更する通信はRESTの状態データだけで、WebSocketのメッセージ形式は変わらない。プロトコルの版は4を維持する。
