# ADR 0037：Entityの値をフィールド単位で同期する

- 状態: 採用・実装済み
- 関連: [Issue #61](https://github.com/katteni-kaihatu/tukurium-prototype/issues/61)

## 理由

同じKokoStateの別フィールドを二人が同時に変えると、値のオブジェクト全体が競合し、一方の編集が失われていた。実際のProjectDocとY.Doc二つの更新交換で再現した。

## 決定

Entityが持つ各KokoStateの値を、フィールドIDをキーにしたY.Mapで保存する。別フィールドは独立して同期し、同じフィールドの競合はYjsの選択に従う。

フィールドへの書き込みは、そのY.Mapを直接更新する。定義の変更も同じMapに反映する。Snapshotとファイルには通常のオブジェクトとして書き出す。

旧形式のY.Docからの移行や、差分を重ねて読む処理は設けない。プロトタイプの既存データは、必要に応じて破棄し、作り直す。

保存形式の変更に合わせ、通信プロトコルを5へ上げる。
