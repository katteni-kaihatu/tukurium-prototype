# ADR 0048：Inspector の詳細は、名前を固定し、KokoState をたためる

- 状態: 採用・実装済み
- 関連：ADR 0040（Hierarchy の複製と削除）、ADR 0044（KokoState を追加する付属パネル）

## 理由

Entity の詳細は、名前も KokoState の欄も一緒にスクロールしていた。KokoState が増えると、いまどの Entity かも、個々の KokoState の中身も、一度に見にくかった。複製・削除・子を作る操作は Hierarchy の行にしかなかった。適用されている System は、詳細の下に常に並んで場所を取っていた。

## 決定

- 名前と、その上の操作は、スクロールの外に置く。スクロールしても名前は見える。
- 操作はアイコンで、複製・削除・子 Entity を作る・KokoState の開閉・適用されている System。編集できないときは、複製・削除・子を作るを押せない。
- 子があるときの複製は、これまでどおり「これだけ」か「中も含めて」を選ぶ。削除の前は確認する。子 Entity は空の Entity で、選んでいる Entity の子にする。
- KokoState は見出しの矢印で、一つずつ閉じられる。上のボタンは、開いているものをすべて閉じ、閉じているときはすべて開く。閉じたときは見出しだけにする。
- 適用されている System は、ボタンを押すとメニューのように上に重なる。名前を押すと、その System の詳細を開く。詳細の下の一覧は出さない。
- 付属パネルと、それを開くボタンの名前は「KokoState を追加」にする。
- Inspector を開いたときの高さは 800（それまでの 2 倍）。上端はこれまでどおりワークスペースの下に置く。画面の高さが足りないときは、下端が画面の中に残るよう縮む。
