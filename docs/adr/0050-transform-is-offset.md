# ADR 0050：Transform が無いときは、初期値の姿勢として扱う

- 状態: 採用・実装済み
- 関連：ADR 0049（空の Entity には Transform を付けない）

## 理由

空の Entity には Transform を付けない（ADR 0049）。そのままだと、姿勢を読む処理が「無い」と「初期値」を別物にした。配置した場所に出ない、重力で落ちた位置が残らない、持てない、といった差が出る。Transform は、初期値からずらしたいときだけあればよい。

## 決定

- Transform が付いていなければ、フィールドの初期値（位置 0、回転 0、拡大率 1）として姿勢を求める。親があるときは、その親からのずれが初期値。
- 描画も物理も、この姿勢を使う。
- クエリの `with: [Transform]` は、Transform が付いている Entity だけに当たる。付いていないものを、付いていることにはしない。
- 配置の位置・向き、動く剛体の結果、持って動かした位置は、初期値からのずれなので Transform に残す。付いていなければ、そのときに足す。子で、まだずれを持っていないものは足さない（親の姿勢に初期値を重ねたままにする）。
- 再生の位置が初期値のままなら、Transform は足さない。
