# ADR 0022：メインメニューの初期範囲と実装単位

- 状態: 採用（2026-11-05）
- 関連: [ADR 0021](0021-main-menu-window.md)、[実装計画](../plans/main-menu-implementation.md)

## 決定

利用者と確認した初期範囲は、無料の入手、所持する版の固定、申請と承認で成立するフレンド、状態・ひとこと・招待までとする。「行ってもいい？」という参加確認は後続に分ける。

- 所持は利用者と作品の組で一件。入手時のリリースを保存し、自動更新しない。所持しても作品の利用権限を上書きしない。自作の作品も明示的に入手する。
- フレンド申請は相手が承認して成立する。申請取消・辞退・関係解除も用意する。表示名ではなく利用者IDで識別する。
- 状態は「参加 OK」「声かけて」「取り込み中」。接続のない人は「オフライン」と表示する。状態は意思の表示であり、セッションや編集の権限を変えない。
- 招待はフレンドへ送る。受け手の参加操作まで移動しない。辞退、期限切れ、セッション終了を扱う。DMと参加確認は作らない。
- 公開セッションの一覧は参加中も更新し、同じ利用者の複数接続を一人として表示する。
- 最初のマーケットは名前・作者の検索、新着順、ページ送り。既存の作品情報を使い、画像未設定は代わりの表示にする。新しい画像設定・カテゴリ分類・決済は別の変更とする。

## 共通ウィンドウ

メニューの表示状態はアプリ全体で持ち、制作ワークスペースやセッションの切り替えでは捨てない。既存のPanelLayerをセッション外でも使えるようにする。メニューは制作パネルと別の一覧で管理し、他者向けのパネル配信には一切含めない。

閉じても画面・検索・選択・大きさを保持する。左上から開き直したときは画面内へ呼び戻せるようにし、空間に置いたまま見失うことを防ぐ。開閉だけではセッションを出ない。

## 一回ずつ確認する範囲

| 単位 | 実装とコミットの範囲 | 確認する結果 |
| --- | --- | --- |
| A1 | 共通ウィンドウ、左上の入口、五つの切り替え先 | 開閉・移動・大きさ変更・2D/3D切替でも制作と入力が保たれる |
| A2 | セッション一覧の更新、参加者、参加・移動・作成 | 二人の入退室が反映され、同じ場所を選んでも再参加しない |
| A3 | 所持の保存、入手API、作品検索、配置結果の応答 | 本人確認、版の固定、重複防止、失敗の理由をテストできる |
| A4 | マーケットとアイテムの画面 | 検索して入手し、所持一覧から現在の場所へ出せる |
| A5 | フレンド申請・承認・解除、状態・ひとこと | 関係を作って、本人向けの一覧と参加先を表示できる |
| A6 | 招待の送信・受信・辞退・参加・期限 | 招待で勝手に移動せず、終了した場所には入らない |
| A7 | ホームへの集約、既存入口の整理、通し確認 | 人を探して参加し、作品を入手して出し、制作へ戻れる |

各単位でADR・計画の実装状況を更新し、検査と画面確認をしてからコミットする。途中段階の未接続画面は完成扱いにしない。最後に全単位の差分と確認結果を計画へ集約する。
