# ADR 0053：道具は E で拾って右手に装備する（EquipmentTool）。Held はなくす

- 状態: 採用・実装済み
- 関連：ADR 0009（右クリックで持つ）、ADR 0016（E の Interact）、ADR 0018（バッグ）

## 理由

銃のサンプルは、Built-in の Held（`player` が空）で「見ている人みんなの手に持つ」形だった。誰が持っているかが決まらず、みんなの入力で同じ銃が撃てた。拾ったり手放したりする、装備の形にしたい。

## 決定（利用者と決めたこと）

- Built-in の **EquipmentTool** を足す。E で見ている EquipmentTool（か、その親）を拾うと、右手に装備する。装備の枠は右手だけ。すでに装備していれば、それはその場に落とす。
- 欄は `offset`・`rotation`（装備している間の、視点に対する位置と角度。右手で前に構えた位置）と、`player`（装備している人。Host が入れる。空なら置いてある）。
- 装備している道具には、**装備している人の入力だけ**が System の `onInput` に届く。EquipmentTool を持たない Entity は、今までどおりみんなの入力を受け取る。
- **T でリングメニュー**を開く。空間に入っている（照準の）ときは、マウスを動かした向きの項目を選び、左クリックで決める（右クリック・T・Esc で閉じる）。マウスを解放しているときは項目を押す。今の項目は「装備を外す」だけ（外すと、その場に落とす。動く剛体なら落ちる）。ほかの項目（移動の仕方など）は、あとで足せるようにしておく。
- ほかの人からは、アバターの右腕が前に出て構えて見え、道具はその手元にある（装備している人の視点は 0.1 秒ごとに Host へ送る）。自分の視点では、道具はカメラに付けて遅れなく手元に見せる。
- 装備はそのセッションの中だけ。別のセッションへは持ち歩かない。
- 拾うには Collider が要る（右クリックで持つ Grabbable と同じ）。セッションでは、Interact と同じく、相手の配置の「外からの見え方」がインタラクション可能なときだけ拾える。
- 銃のサンプルは EquipmentTool にし、再生を始めた位置の少し前に置く。
- **Held はなくす**。右クリックで持つ仕組みは残し、持っている人と、持った瞬間の視点からの位置関係は Grabbable の欄（`player`・`offset`・`rotation`。Host が入れる）に持たせる。

- 適用（作品の新しい版を入れる）で Entity を作り直しても、装備・右クリックで持っている状態と位置は保つ（遊んでいる最中に手から消えないように）。リセットでは外れる。

## 残したこと

- 装備した人がセッションを出ても、道具は装備されたまま残る。
