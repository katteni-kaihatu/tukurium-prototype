# ADR 0025：申請と承認でフレンドになり、状態と参加先を共有する

- 状態: 採用・実装済み（2026-11-05、A5）
- 関連: [ADR 0022](0022-main-menu-first-release.md)

## 決定

フレンド関係は二人につき一件。申請した人と受け取った人を記録し、受け手だけが承認できる。双方から申請しても自動承認しない。再送は同じ申請を返し、取消・辞退・関係解除はその関係を削除する。送信中の申請は一人50件までにする。

本人確認付きの名前・ID検索で相手を探す。検索結果には名前、ID、本人との関係だけを返す。承認済みのフレンド一覧で初めて、相手の状態・ひとこと・接続状況・参加先を返す。

状態は「参加 OK」「声かけて」「取り込み中」。ひとことは120文字以内。これらは保存する本人の設定であり、セッションや編集の権限を変えない。オンライン状態と参加先はHubの実際の接続から求め、複数タブの一つが閉じただけではオフラインにしない。

関係や状態の変更、入退室・接続・切断は、本人と関係する相手へ `social.changed` を送って一覧を取り直す。メニューは専用の非公開データとして保持し、他者の制作パネルには配信しない。

## 確認

PostgreSQLとメモリ保存で、申請の重複、受け手の承認、状態保存、解除を確認した。APIでは本人確認、自己申請の拒否、第三者や申請者による承認の拒否、承認前の情報制限、複数タブ、参加先、解除後の一覧を検査した。

二人分のブラウザで名前・ID検索から申請、受信・承認、状態の更新、フレンドの場所への合流、関係解除まで確認した。全体の単体テスト334件、lint、型検査、ビルドが成功した。
