# ADR 0029：上のバーから独立したウィンドウを開く

- 状態: 採用・実装済み（2026-11-05）。入口の配置は [ADR 0031](0031-global-navigation-and-session-bar.md) で変更。
- 置き換え: [ADR 0021](0021-main-menu-window.md) と [ADR 0027](0027-main-menu-integration.md) の「一つのウィンドウ内で画面を切り替える」という構成
- 補足: ワークスペースの入口は [ADR 0030](0030-workspace-switcher-display.md) で旧表示へ戻した。
- 継続: [ADR 0028](0028-session-and-optional-workspace.md) の、セッションと編集を分ける考え方

## 決定

ホーム・フレンド・セッション・アイテム・マーケットは、それぞれ独立したウィンドウにする。フレンドを見ながらアイテムを探すなど、複数を並べて使えるようにする。上のツクリウムボタンでホームを開き、ほかの画面には上のバーから直接入る。

プロジェクトと制作対象の選択も独立したウィンドウとして開く。「ワークスペース」は編集中の画面を手前へ呼び戻し、未編集なら編集対象を選ぶ画面を開く。ライブラリ・ワールド・バッグのボタンも上のバーに残し、「その他」の中へまとめない。狭い画面ではバーを横にスクロールして選べる。

## 操作

- ウィンドウごとに、開閉・位置・大きさ・画面への固定・3D空間への配置を保持する。
- バーのボタンは対象のウィンドウを開き、画面内の手前へ呼び戻す。他のウィンドウは閉じない。
- ウィンドウ内から別の機能を選んだ場合は、そのウィンドウを開く。検索や選択、入力中の内容を捨てない。
- 閉じるボタンはそのウィンドウだけを閉じる。Esc は最後に操作したウィンドウだけを閉じる。
- セッションへの参加や編集開始が成功したら、操作元のウィンドウだけを閉じる。他のウィンドウはそのまま使える。
- 表示や操作は本人だけのものとし、他の参加者向けには配信しない。

セッションの参加状態と、制作中のプロジェクトは維持する。ウィンドウを開いたり閉じたりしただけでは、ワークスペースを作成・終了しない。

## 確認

5つのウィンドウの同時表示、個別の開閉、検索・新規プロジェクトの下書き保持、ドラッグとサイズ変更、3D配置からの呼び戻しを確認した。参加中も同じセッションと3Dエンジンを保つ。ワークスペースの呼び戻しと、狭い画面でバーの各ボタンを選べることも確認した。
