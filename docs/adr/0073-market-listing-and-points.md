# ADR 0073：マーケットには作者が登録したものだけを出し、ポイントで買う

- 状態: 採用・実装済み
- 関連：ADR 0024（所持と入手）、ADR 0034（公開タグ）、ADR 0047（作品の詳細）、ADR 0066（ワールドの画面）、ADR 0071（所持アイテムのアップデート）

## 理由

これまでのマーケットには、プロジェクトでリリースしたアイテムがすべて自動で並んでいた。作者が「売る」と決めたものだけを出し、値段を付けられるようにしたい。デザイン（T4・T4b・T4c）は、検索・種類とタグの絞り込み・並べ替えの一覧、価格と入手の詳細、自分の作品を管理するマイページと登録のダイアログを示している。

## 決定

- マーケットに出るのは、作者がマイページで「登録する」としたリリースだけ。登録していないリリースは、マーケットに出ないだけで、これまでどおり利用の権限で使える。
- 売れるのはアイテムとワールド。ライブラリは import で使うので登録できない。アバターはまだないので、絞り込みに出さない。呼び名は「アイテム」のまま（デザインの「プロップ」にはしない）。
- 登録では、価格（0〜100,000 P、0 は無料）・公開タグ（作品のタグ。ADR 0034 と同じもの）・自動公開を決める。自動公開がオンなら、新しい版をリリースしたときマーケットでもその版を公開する。オフなら、公開する版を自分で選ぶ。編集で価格・タグ・自動公開・公開する版を変え、登録を取り消せる。取り消しても、入手した人はそのまま使える。
- 所持金はポイント（P）で、はじめは 1,000 P。買うと価格を引き、作者に価格の 9 割（切り捨て）が入る。残りは消える。所持金が足りなければ買えない。引くこと・作者に足すこと・所持・記録は、ひとまとまりで行い、同時に買っても一度しか払わない。
- 入手できるのは公開中の版。もう持っていれば払わない。新しい版へのアップデートは無料だが、公開中の版より新しい版には替えられない。作者は自分の作品を無料で持てる（記録に残さない）。
- マイページに入手の記録（日時・作品・版・価格・受け取ったポイント）を出す。誰が入手したかは作者にも見せない。
- 作品の詳細に、誰でも見える履歴（登録・版の公開・価格の変更・取り消し）を出す。入手の記録は含めない。
- 並べ替えは新着順（登録した順）・人気順（入手した人の数）・安い順。
- ワールドの画面には、すべてのワールドを出す。有料で入手していないワールドは鍵の印を付け、開く代わりにマーケットの詳細へ移るボタンを出す。サーバーも、有料で入手していないワールドを開くこと・アイテムを置くことを断る。
- 入手したワールドは所持一覧にも並び、「ワールドを見る」でワールドの画面へ移る。

## API

- `GET /api/market` に `kind`（all・item・world）と `sort`（new・popular・cheap）を足す。登録したものだけを返し、各作品に `market`（価格・自動公開・公開中の版・登録日・入手の数）を付ける。
- `POST /api/market/listings`・`PATCH /api/market/listings/:workId`・`DELETE /api/market/listings/:workId` で登録・編集・取り消し。
- `POST /api/me/items/:workId` は版を受け取らず、公開中の版を入手して、残りの所持金を返す。足りなければ 402。
- `GET /api/me/wallet` で所持金、`GET /api/me/market` でマイページ（登録したもの・登録していないもの・入手の記録）。
- `GET /api/works` の各作品に、マーケットの価格 `price` と、見ている人が使えるか `unlocked` を付ける。
- 保存は、所持金・登録・履歴・入手の記録の表を足す。既存のデータは移さない（すべて未登録から始まる）。
