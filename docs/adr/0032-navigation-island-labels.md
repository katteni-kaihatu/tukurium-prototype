# ADR 0032：補助メニューを独立した島にし、マウス操作時に名前を出す

- 状態: 採用・実装済み（2026-11-05）。補助メニューは [ADR 0061](0061-global-navigation-menu.md) でグローバルメニューに置き換えた
- 変更: [ADR 0031](0031-global-navigation-and-session-bar.md) の、上のバーと補助メニューをつなげる表示

## 決定

上のバーを主な表示とする配置は保ち、左の補助メニューは少し間を空けた独立した島にする。上のバーも四隅を丸める。

3D空間を操作している間は、補助メニューをアイコンだけにする。ポインターロックが解除され、通常のマウス操作へ戻ったら、6つのアイコンに名前を表示する。参加前も名前を表示する。ブラウザの `pointerlockchange` に合わせて切り替える。

広い画面ではアイコンの横に名前を表示する。狭い画面では列の幅を保ち、アイコンの下に名前を出す。ウィンドウの初期位置と呼び戻し先は、名前の表示領域を避ける。

アプリ全体の入口を左、現在のセッションの操作を上に置くこと、各機能の独立ウィンドウ、ワークスペースの旧表示は変えない。
