# ADR 0056：変わった欄の戻す印は左に置き、確認してから戻す

- 状態: 採用・実装済み
- 関連：ADR 0040（変化の丸）、ADR 0041（差分の書き方と、保存パネルでの戻す）

## 理由

丸にマウスを載せると、どう変わったかがその下に出る。戻すボタンは右端にあり、文字も付いていた。丸のそばからすぐ押せない。戻すと最後に保存した形へ書き換わるので、押し違えると困る。

## 決定

- 戻すボタンは、出たパネルの左端に置く。文字は出さず、戻す印だけにする。ボタンの名前は「元に戻す」のまま残す。
- 押したら、戻す前に確認する。新しいものは消えること、消えたものは戻ることを、文に書く。取り消したときは、マウスがまだ載っていればパネルを開いたままにする。
- 保存パネルと履歴の戻すボタンは、これまでどおり文字なしの印で、確認は出さない。
