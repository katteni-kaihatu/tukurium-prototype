# ADR 0040：Hierarchy の親子と、保存との差の丸

- 状態: 採用・実装済み

## 理由

Entity の親は一覧の横のメニューからしか変えられず、親子が深いときに全体をたたんで見られなかった。複製と削除も、選んだあとに上のボタンを押す形で、行の上からは触れなかった。どこが新しくて、どこが最後の保存から変わったかも、履歴を開かないと分からなかった。

## 決定

- Hierarchy では、Entity をドラッグして行の上端か下端に置くと、同じ親の兄弟としてその位置に並べる。行の真ん中に置くと、その子にして末尾に入れる。アウトプットの行に置くと、親を外していちばん上の末尾に置く。自分自身と、その中にある Entity の上には置けない。子がある行だけ矢印を出し、開いたり閉じたりする。子がない行は矢印を出さず、名前がずれないよう同じ幅を空ける。
- 行にポインタを合わせるか、その行を選ぶか、キーボードで焦点を合わせると、複製と削除が出る。子があるときは、その Entity だけ複製するか、中も含めて複製するかを選ぶ。子がないときは、その場で複製する。Entity を削除する前に確認する。中に Entity があるときは、一緒に消える数も知らせる。
- 緑の丸は、最後に保存した内容にない新しいもの。黄色の丸は、そこから変わったもの。変化がないところにも、中が透けた丸を置いて、文字の開始を揃える。丸は行の左に置く。Hierarchy では Entity ごと、Inspector のプロパティと詳細では変わった欄ごとにつける。閉じた行は、中に変化があればその丸を出す。
- 比べる相手は、リポジトリに最後に保存したファイル。保存がまだ読めていないあいだは丸を出さない。並び順だけの違いは丸にしない。
- 詳細で KokoState を削除するときは、使っている Entity が無くても確認する。使っているときは、外れる数も知らせる。

Play 中の Hierarchy は、これまでどおり実行中の世界を見せ、編集の操作と丸は出さない。
