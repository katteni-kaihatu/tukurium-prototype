# ADR 0061：左の入口を、開いてもたためるグローバルメニューにする

- 状態: 採用・実装済み（2026-11-10）
- 変更: [ADR 0032](0032-navigation-island-labels.md) の補助メニュー（6 項目・ポインターロックで名前を出し入れ）。[ADR 0031](0031-global-navigation-and-session-bar.md) の、退出を上のバーに置くこと
- 継続: [ADR 0029](0029-independent-tool-windows.md) の独立したウィンドウ

## 背景

UI をトナリウムに寄せる（デザイン「ツクリウム デザイン（実装から）」の統合案）。統合案では、左の入口をトナリウムと同じ構成のグローバルメニューにし、ホームでは名前つき、セッション内ではアイコンの列にたたむ。

## 決定

1. 左の補助メニューを、グローバルメニューに置き換える。いちばん上のボタンで、名前つきの形（幅 228px）とアイコンの列（幅 64px）を切り替える。参加前は開き、セッション内と狭い画面（幅 1000px 以下）ではたたんだ形で始める。3D 空間を操作している間（ポインターロック中）は、いつもアイコンの列にする。
2. 項目はホーム・タイムライン・フレンド・セッション・イベント・グループ・ワールド・アイテム・マーケット・プロジェクト・ワークスペース・ライブラリの順。いまのツクリウムに画面がないタイムライン・イベント・グループ・ワールドは、ボタンだけを置き、押しても何もしない。
3. ライブラリは残す。依存を足す・外す操作と、リリースをセッションに置く操作は、ほかに入口がないため。
4. 下に、クライアントモード（2D/3D。ボタンだけ）、セッション内なら退出（持ち主は「セッションを閉じる」、ほかの人は「セッションを出る」）、自分の顔・名前・ステータスを置く。自分の顔を押すとステータスのウィンドウを開く。歯車（アイコン・アバター・自己紹介の設定）はボタンだけ。
5. メニューの右端から 16px を、ウィンドウの初期位置と呼び戻し先の左端（`--app-content-left`）にする。開く・たたむに合わせて変える。
6. 色と文字は、いまのツクリウムの値を使う。

## この記録で決めないこと

上のバーをなくし、セッションの情報や参加者を左右の欄へ移すことは、続きの段階で決める。所属グループの一覧は、グループの仕組みがないので置かない。
