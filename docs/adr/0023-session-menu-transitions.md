# ADR 0023：参加先を受理してからセッションを切り替える

- 状態: 採用・実装済み（2026-11-05、A2）
- 関連: [ADR 0022](0022-main-menu-first-release.md)

## 決定

公開セッションの一覧を参加中にも配信する。参加者の名前・持ち主・人数を含め、同じ利用者の複数接続は一人にまとめる。名前や参加者の検索はこの一覧を使う。

移動の前にルートを変えると、元の制作やセッションを先に閉じてしまう。そこで参加要求に要求IDを付け、サーバーは移動先を確認した後で `session.entered` を返す。見つからない場合は `session.rejected` を返し、現在の参加先を維持する。受理の通知を受けてから古い制作・実行状態を片付け、新しいセッション情報を受け取ってルートを変える。

同じセッションを選んだときはメニューを閉じるだけ。別の場所へ移るときは確認を出し、持ち主には元のセッションが閉じる条件も伝える。セッション画面のルート引数の変更と、画面から完全に退出する処理を分ける。

通信の版は4へ上げる。セッションの寿命、編集権限、ホストの仕組みは変えない。

## 確認

サーバーの単体テストで参加中の一覧更新、複数タブの集計、失敗時の参加先維持を確認した。二人分のブラウザでは、名前の検索、参加者一覧、編集中の別セッションへの移動、現在地へ戻る操作を通した。
