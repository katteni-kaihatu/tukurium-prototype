# ADR 0041：履歴と保存の差分は、名前と中身で出す

- 状態: 採用・実装済み

## 理由

履歴と保存の差分は、保存形式のファイル名と増減した行数だけだった。エンティティやアウトプットの名前が分からず、階層や KokoState、コード、素材の見た目も開かなかった。

## 決定

- 未保存は、最後に保存した制作データと、いまの制作データを比べる。記録は、その記録と親の記録を比べる。最初の記録は、空と比べる。
- 一覧はファイル名ではなく名前にする。エンティティ、アウトプット、コード、KokoState、マテリアル、モデル、テクスチャ、音声、その他に分ける。
- 行を押すと詳細を出す。エンティティは階層のパスと、変わった KokoState の欄の前後。アウトプットは種類、システム、状態維持などの前後。コードは変わった行。モデルとテクスチャは、左に変更前、右に変更後の見た目。変わった行から離れたコードは省略する。
- モデルの見た目は、その行を開いているあいだだけ描く。

ファイルそのものの差分（パスと行数）は、プロジェクトのページに残す。
