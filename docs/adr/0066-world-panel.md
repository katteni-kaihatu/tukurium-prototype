# ADR 0066：ワールドのウィンドウから、セッションのルートワールドを変える

- 状態: 採用・実装済み（2026-11-11）
- 変更: [ADR 0061](0061-global-navigation-menu.md) の、ワールドはボタンだけで押しても何もしない、を置き換える
- 継続: [ADR 0014](0014-session-open-world.md) の、開くワールドは一つで、入れ替えるとアイテムは残る。[ADR 0029](0029-independent-tool-windows.md) の独立したウィンドウ

## 背景

グローバルメニューに「ワールド」があるが、押しても何も開かなかった。セッションのルートワールドを変える入口は、ワークスペースの「セッション」にしかなく、変えた瞬間に入れ替わっていた。セッションにいないときは、ワールドを選んで部屋を開く入口がなかった。

## 決定

1. グローバルメニューの「ワールド」は、独立したウィンドウ「ワールド」を開く。公開されているワールド（最新のリリース）を並べ、名前と作者で探せる。
2. セッションにいるときは、選んだワールドをそのセッションのルートワールドにする。入れ替えの規則は ADR 0014 のまま。いま開いているワールドは外れ、選んだリリースが原点に一つ置かれ、アイテムは残る。すでにそのリリースだけが開いているときは、何もしない。
3. 入れ替えの前に、サーバーが 3 秒数えてから変える。そのあいだ、セッションの全員の画面中央に、残り秒数と、変える先の名前と、変えようとした人の名前を出す。予定はセッションの状態に載せるので、途中から参加した人も残り時間を見る。
4. 数えているあいだに別のワールドを選ぶと、前の予定をやめて、新しい 3 秒を始める。同じワールドをもう一度選んでも、数え直さない。頼み人が抜けても、数え終わったら入れ替える。セッションが閉じたら、入れ替えない。
5. セッションにいないときは、選んだワールドの名前を初期値にして、セッションの名前を決めて開ける。そのワールドを最初から開く。新しいセッションなので、カウントダウンは出さない。
6. ワールドでない、見つからない、利用の権限がないリリースでは、セッションを作らず、カウントダウンも始めない。
7. ワークスペースの「セッション」から開くときも、同じカウントダウンのあとで入れ替える。
8. 通信は、`session.create` に任意の `worldReleaseId` を足し、セッションの状態に任意の `worldChange` を足す。無いときは、これまでの動作。`PROTOCOL_VERSION` は上げない。

## この記録で決めないこと

カウントダウンを取り消すボタンは置かない。別のワールドを選べば、予定は入れ替わる。セッションの名前を、作ったあとから変えることはしない。
