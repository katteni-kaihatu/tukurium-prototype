# 0081: 画面のパネルを 1 枚のキャンバスに乗せる

日付: 2026-11-16

## 判断

画面に固定した（2D の）パネルは、すべて 1 枚の「キャンバス」に乗っているものとして扱う。Figma と同じように、ホイールを押し込んだままドラッグするとキャンバスごと動き、Ctrl＋ホイールで拡大・縮小する。

- キャンバスの見え方（ずらし量と倍率）は 1 つだけ持ち（`panels/panelCanvas.ts`）、メインメニューのウィンドウとワークスペースのパネルが共有する。
- パネルの位置はキャンバスの座標で持つ。画面の位置は「位置 × 倍率 ＋ ずらし量」。各パネルの入れ物に CSS の変形（左上を原点に `translate` と `scale`）をかける。キャンバスを動かしても React は描き直さず、変形だけを直す。
- キャンバス全体を包む要素に変形をかけると、そこで重なりの順の文脈が切れ、2 つのパネルの層の間で前後を入れ替えられなくなる。そのため変形はパネルごとにかける。
- 拡大・縮小はカーソルの位置を動かさずに行う。倍率は 25%〜200%。
- 空間に置いた（3D の）パネル、パネルの外の画面（ナビゲーション・ヘッダーなど）、パネルから出るメニューや説明の窓は、キャンバスに乗せない。
- 空間に入っている間（ポインターロック中）は何もしない。空間の操作を優先する。右ボタンで 3D のパネルを持っている間の Ctrl＋ホイールも、空間に任せる。
- 見えている 2D のパネルがないときは、ホイールクリックも Ctrl＋ホイールもブラウザに任せる（ページの拡大・自動スクロール）。
- ホイールクリックでドラッグしたあとは、そのクリックを貼り付けやリンクを新しいタブで開く操作にしない。動かさずに離したときは、ふつうのホイールクリックとして扱う。
- キャンバスを動かしたか拡大・縮小したときだけ、右下に倍率と「元に戻す」を出す。パネルを見失ったときの逃げ道。見え方は保存しない（読み込み直すと等倍に戻る）。

## パネルの操作との関係

- タイトルバーのドラッグは、画面の移動量を倍率で割ってキャンバスの座標に足す。タイトルバーが画面の上へ出ないよう、画面の上端で止める。
- 大きさの変更は、画面の矩形と配置の大きさの比を使っているので、そのまま倍率に合う。画面の端までに収める上限は、いまの見え方でキャンバスの座標に直して比べる。
- 開いたパネルは、開いた時点の見え方で、画面の上の決まった場所に出す。いったん出したら、キャンバスと一緒に動く。
- 開き直したとき（呼び戻し）は、画面の上で作業領域の中に寄せる。
- 中身に合わせて高さが変わるパネルの上限は、置いた・動かしたときの画面の下端まで。キャンバスを動かすだけでは変えない（動かすたびにパネルの高さが変わらないように）。
