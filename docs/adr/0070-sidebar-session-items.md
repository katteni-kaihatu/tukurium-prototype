# ADR 0070：セッションに出ているアイテムは、左の欄に並べる

- 状態: 採用・実装済み（2026-11-12）
- 関連: [ADR 0062](0062-session-tag-and-sidebar.md)、[ADR 0069](0069-session-items-in-item-list.md)

## 理由

0069 では、出したアイテムを所持アイテムのカードに出した。利用者が見ていたのは、セッションの左の欄にある「アイテム」だった。そこには件数と、「セッションに出ている作品」という一つの行しかなく、個々のアイテムは並ばない。

## 決定

セッションに出ているアイテム（ワールドは含めない）は、左の欄の「アイテム」に、名前と出した人で並べる。

- 件数は、並んでいるアイテムの数にする。
- 外せるのは、セッションの持ち主、その配置を出した人、そのワークスペースを編集できる人。行に「外す」を置く。
- ワールドを開く行とバッグの行は残す。ワールドの行は、開いているワールドの名前を出す。
- 所持アイテムのカードには出さない。

## 確認

アイテムをセッションに出すと、左の欄の「アイテム」にその名前が並ぶ。「外す」で配置が消える。
