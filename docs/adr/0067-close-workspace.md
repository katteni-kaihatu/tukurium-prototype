# ADR 0067：ワークスペースを出ることと、閉じることを分ける

- 状態: 採用・実装済み（2026-11-11）
- 関連: [ADR 0028](0028-session-and-optional-workspace.md)、[ADR 0030](0030-workspace-switcher-display.md)、[ADR 0005](0005-sessions-identity-host.md)

## 背景

ワークスペースの「閉じる」は、自分だけ編集を終える操作だった。ワークスペースはセッションの一覧に残る。一覧からなくす操作がなかった。

## 決定

- 「出る」は、自分だけ編集を終える。ワークスペースはセッションに残り、ほかの人は開いたままにできる。セッションにも残る。
- 「閉じる」は、ワークスペースをそのセッションの一覧からなくす。開いていた人も出る。押す前に確認する。
- 閉じられるのは、そのワークスペースの管理権限を持つ人。入っていなくても、一覧から閉じられる。
- 閉じる前に制作データを保存する。プロジェクトは残る。あとから開き直せる。
- セッションに出した配置は残る。ワークスペースを開き直すと、同じプロジェクトの配置はまたそのワークスペースにつながる。

## 確認

サーバーのテストで、出ても残ること、管理でない人が閉じられないこと、管理者が閉じると一覧から消えて開いていた人に届くこと、保存した内容が残りもう一度開けることを確かめる。画面では、編集中の「出る」「閉じる」と、一覧で入っていないワークスペースの「閉じる」、確認を取り消すと残ることを見る。
