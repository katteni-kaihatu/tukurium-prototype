# ADR 0057：アイテムとワールドは、動作上の親 Entity を一つ持つ

- 状態: 採用・実装済み
- 関連：ADR 0050（Transform は初期値からのずれ）。0050 の「配置の位置を、親のない Entity の Transform に足す」は、この ADR で置き換える

## 理由

セッションに出すと、配置の位置と向きを、親のない Entity それぞれの Transform に直接足していた。System は親からのずれ（ローカル座標）として値を書く。足したあとはその値がセッションの座標になり、置いた場所から飛んだり、向きが二重になったりした。

ワークスペースの再生も、あとからワークスペース自体を動かせるように、同じ形にする。

## 決定

- ワークスペースの再生でも、セッションの配置でも、アイテムとワールドには動作上の親 Entity を一つ作る。ID は `__root`（セッションでは `配置ID/__root`）。名前はアウトプットの名前。
- 制作データで親がない Entity は、この親の子にする。中の Transform は、制作データのまま残す。
- 配置の位置と向きは、この親の Transform だけが持つ。ワークスペースの再生では、位置 0・向き 0 の Transform を付ける。ずれが無くても親は作る。
- 親を指定せずに作った Entity も、呼んだ配置のこの親の子にする。
- この親は、`world.find` では名前が一致しても返さない。`world.destroy` でも消さない。
- 持つ・装備するときの「いちばん上」は、制作データで親がない Entity。動作上の親の直下も、いちばん上として扱う。
- 動く剛体の結果は、親から見たずれとして Transform に戻す。持った位置・装備した位置も、ワールドの位置を求めてから、親から見たずれとして残す。
