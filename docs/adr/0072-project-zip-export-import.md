# ADR 0072：プロジェクトを Zip でエクスポート・インポートする

- 状態: 採用・実装済み（2026-11-13）
- 関連: [ADR 0007](0007-repos-commits-works.md)（リポジトリ・作品）、[ADR 0038](0038-extract-into-editable-repo.md)（抽出）、[ADR 0046](0046-output-thumbnail.md)（サムネイル）

## 背景

プロジェクトの中身を手元に残したり、別の Tukurium のサーバーへ持っていったりする手段がなかった。フォーク・抽出は同じサーバーの中だけで使える。

## 判断

- プロジェクトの画面に「Zip でエクスポート」を置く。`GET /api/repos/:id/export` が Zip を返す。
- Zip に入れるのは、**最新の保存（コミット）だけ**と、それが使う素材の本体。保存の履歴は入れない（利用者と決めた）。
  - `tukurium-project.json`：名前・説明・種類・書き出したときのプロジェクトとコミット・素材の種類
  - `project/…`：リポジトリの中と同じ並びのファイル（人が読める JSON と `.ts`）
  - `asset-files/<素材 ID>`：素材の本体。ID は中身の SHA-256。使う素材は、素材の一覧とアウトプットのサムネイル。素材置き場に見つからないものは入れない
- エクスポートできるのは、**フォークできる人**（フォーク・抽出と同じ許可。利用者と決めた）。保存がまだないプロジェクトは書き出さない。
- 新しいプロジェクトの画面に「Zip からインポート」を置く。`POST /api/repos/import` に Zip の本文（`application/zip`）を送ると、**新しいプロジェクト**を作る（利用者と決めた）。持ち主は取り込んだ人で、名前（空なら Zip の中の名前）と公開範囲を選べる。履歴は「最初のコミット」から始まる。既存のプロジェクトは書き換えない。
- 取り込むときは次を確かめ、合わなければ 400 で拒む：Zip として読めるか、`tukurium-project.json` と `project/tukurium.json` があるか、パスが上へたどったり絶対パスだったりしないか、素材の ID が中身の SHA-256 と一致し、種類が受け付けるもので、先頭のバイトが種類と合うか。大きさにも上限を置く（Zip 200 MB・展開後 400 MB・制作データ 20 MB・素材 1 つ 20 MB）。
- 由来（provenance）は、Zip の中の `provenance.json` をそのまま引き継ぎ、インポートの由来は足さない。書き出したときのプロジェクトは `tukurium-project.json` に残るが、別のサーバーではたどれないことがあるため。
- 依存しているライブラリは、そのまま参照を残す。別のサーバーでは見つからず、使えない依存として出る。
- Zip の読み書きには `fflate` を使う（サーバーだけ）。

## 確認

- `apps/server/src/app.test.ts` の「プロジェクトを Zip にエクスポートし、素材ごと新しいプロジェクトへインポートする」：権限、Zip の中身、素材を含めた取り込み、名前と公開範囲、壊れた Zip・違う中身の素材・上へたどるパスの拒否、本人確認。
