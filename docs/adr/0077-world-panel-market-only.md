# ADR 0077：ワールドの画面にはマーケットにあるワールドだけを出し、自分の作品は「自分のワールド」「自分のアイテム」に分ける

- 状態: 採用・実装済み（2026-11-14）
- 変更: [ADR 0073](0073-market-listing-and-points.md) の「ワールドの画面には、すべてのワールドを出す」と、[ADR 0066](0066-world-panel.md) §1 の「公開されているワールド（最新のリリース）を並べる」を置き換える
- 継続: ADR 0066 のカウントダウンと入れ替えの規則。ADR 0073 の、有料のワールドは作者か入手した人だけが開ける

## 背景

ワールドの画面は、リリースされたすべてのワールドを並べていた。マーケットに登録していない作品や、作者が試しに出しただけのワールドも混ざり、マーケットで選んで買う流れと合っていなかった。

## 決定

1. ワールドの画面には、マーケットに登録され、公開中の版があるワールドだけを、マーケットと同じカードで並べる。一覧はマーケットの検索（種類はワールド）から読む。登録していないワールドは、作者のものでも、この一覧には出さない。
2. 開くのは、マーケットで公開している版。最新のリリースではない。
3. 無料のワールドと、作者か購入した人の有料のワールドは、その場で開ける（セッションを開く・セッションのワールドを変える）。印は「無料」「入手済み · 価格」。
4. 購入していない有料のワールドは、鍵の印を付け、開くボタンの代わりに「マーケットで購入する」を出す。押すと、マーケットのその作品の詳細へ移る。購入すると、ワールドの画面の鍵はすぐに外れる。
5. 見出しの右に「自分のワールド」と「マーケットで探す」を置く。「マーケットで探す」は、マーケットを種類「ワールド」で開く。
6. 「自分のワールド」を押すと、自分がリリースしたワールドだけの一覧に移る（「← マーケットのワールドへ戻る」で戻る）。マーケットに出していない非公開のワールドは、ここにだけ出る。開くのは最新のリリース。カードには「非公開」か「マーケット · 価格」を出す。マーケットに出しているかを、一覧の段階ではっきり分けるため、タブではなく別の一覧にする。
7. アイテムの画面にも、同じく「自分のアイテム」を置く。押すと、自分がリリースしたアイテムだけの一覧に移る（「← 所持アイテムへ戻る」で戻る）。非公開のアイテムはここにだけ出る。作者は入手しなくても自分の作品を使えるので、所持アイテムには加えずに、最新の版をそのまま取り出す。
8. 自分の作品の一覧は `/api/me/market`（マイページと同じ）から読み、種類で分ける。
9. `/api/works` から、ワールドの画面だけが使っていた `price` と `unlocked` を外す。

## この記録で決めないこと

ワークスペースの「セッション」から開く入口（ADR 0066 §7）と、サーバーがワールドを開く・アイテムを置くときの判定は変えない。所持アイテムに入っている自分の作品は、そのまま所持アイテムにも残る。
