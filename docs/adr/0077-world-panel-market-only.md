# ADR 0077：ワールドの画面には、マーケットにあるワールドだけを出す

- 状態: 採用・実装済み（2026-11-14）
- 変更: [ADR 0073](0073-market-listing-and-points.md) の「ワールドの画面には、すべてのワールドを出す」と、[ADR 0066](0066-world-panel.md) §1 の「公開されているワールド（最新のリリース）を並べる」を置き換える
- 継続: ADR 0066 のカウントダウンと入れ替えの規則。ADR 0073 の、有料のワールドは作者か入手した人だけが開ける

## 背景

ワールドの画面は、リリースされたすべてのワールドを並べていた。マーケットに登録していない作品や、作者が試しに出しただけのワールドも混ざり、マーケットで選んで買う流れと合っていなかった。

## 決定

1. ワールドの画面には、マーケットに登録され、公開中の版があるワールドだけを並べる。一覧はマーケットの検索（種類はワールド）から読む。登録していないワールドは、作者のものでも出さない。
2. 開くのは、マーケットで公開している版。最新のリリースではない。
3. 無料のワールドと、作者か購入した人の有料のワールドは、その場で開ける（セッションを開く・セッションのワールドを変える）。印は「無料」「入手済み · 価格」。
4. 購入していない有料のワールドは、鍵の印を付け、開くボタンの代わりに「マーケットで購入する」を出す。押すと、マーケットのその作品の詳細へ移る。購入すると、ワールドの画面の鍵はすぐに外れる。
5. 見出しに「マーケットで探す」を置く。押すと、マーケットを種類「ワールド」で開く。
6. `/api/works` から、ワールドの画面だけが使っていた `price` と `unlocked` を外す。

## この記録で決めないこと

ワークスペースの「セッション」から開く入口（ADR 0066 §7）と、サーバーがワールドを開くときの判定は変えない。作者は、登録していない自分のワールドを、これまでどおりワークスペースから開いて確かめられる。
