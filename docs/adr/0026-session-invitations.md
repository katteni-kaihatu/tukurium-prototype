# ADR 0026：フレンドを現在のセッションへ招待する

- 状態: 採用・実装済み（2026-11-05、A6）
- 関連: [ADR 0022](0022-main-menu-first-release.md)、[ADR 0025](0025-friend-requests-and-presence.md)

## 決定

参加中のセッションから、承認済みのフレンドへ招待を送れる。送信者はそのセッションに参加している必要がある。受け取った人は招待を受けて参加先を見るか、辞退する。送信者は取り消せる。

招待を受けても、サーバーは参加や移動を実行しない。メニューで参加先の詳細を開き、本人が参加ボタンを押したときだけ移動する。編集権限も付与しない。

有効期限は10分。同じ送信者・相手・セッションの有効な招待は一件にまとめ、再送で増やさない。送信中は一人50件まで。受け手だけが承認・辞退し、送信者だけが取り消せる。応答済みの状態は上書きしない。

セッションが終了した招待は期限切れとして返す。フレンドを解除したときは未応答の招待も取り消す。表示中の招待は通信で更新し、時刻による期限切れも取り直す。保存先は既存Storeに追加し、PostgreSQLでも履歴を保持する。

## 確認

PostgreSQLとメモリ保存で同時送信の重複、応答者、期限、応答後の保持を確認した。APIではフレンド以外の拒否、第三者の応答拒否、受信だけで移動しないこと、辞退・期限切れ・セッション終了を検査した。

二人のブラウザで招待、受信、参加先の表示、本人による参加まで通した。全体の単体テスト337件、lint、型検査、ビルドが成功した。
