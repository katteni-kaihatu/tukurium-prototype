# ADR 0021：左上から開くメインメニューに五つの画面をまとめる

- 状態: 採用（2026-11-05、画面構成と入口）
- 関連: [ADR 0020](0020-social-workshop-direction.md)の初期UI範囲を具体化する。[ADR 0003](0003-panels-2d-3d.md)のパネル操作を引き継ぐ。
- 完了記録: [メインメニュー](../archive/main-menu-implementation.md)。この記録の後に[ADR 0022](0022-main-menu-first-release.md)で実装範囲を確定し、初期版を実装した。

## 背景

ソーシャルと公開アイテムの画面モックを確認し、利用者からホーム・フレンド・所持アイテム・マーケットを加える要望があった。さらに、左上のツクリウムボタンで開くウィンドウとして扱うことを確認した。

## 決定

1. 一つのメニューウィンドウ内で、ホーム・フレンド・セッション・アイテム・マーケットを切り替える。
2. 左上のツクリウムボタンから開閉する。メニューの開閉や内部の切り替えでは、セッションの退出や再参加を行わない。
3. 制作のパネルと同様に扱い、移動・サイズ変更・画面への固定・3D空間への配置を共通の操作へつなぐ。2Dクライアントは作らない。
4. 「アイテム」は自分の所持一覧、「マーケット」は公開作品を探して入手する入口とする。ゲーム内のバッグや、制作へ組み込むライブラリとは区別する。
5. まず `feat/main-menu` で実装計画を具体化する。今回の作業では本体へ実装しない。

## この記録で確定しないこと

フレンドの成立方式、所持する版と更新、状態や招待の範囲、サムネイルと分類の保存方式は実装計画で比較する。モックの架空データや無料表示を、そのままサービスの運用仕様にはしない。

既存のセッションの寿命、作品・ワークスペースの権限、配布・再利用の仕組みは変更しない。ADR 0020のソーシャルの方向性は維持する。
