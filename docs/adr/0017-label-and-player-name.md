# ADR 0017：文字（Label）と、入力に添える表示名

- 状態：採用（2026-11-04）
- 関連：ADR 0010（import）、ADR 0012（本人の確定は ID。クライアントの申告）

## 背景

マルバツのサンプルで、先行と後攻の名前、いまの様子、リセットの案内を空間に出したかった。画像を用意すると、プレイ中に名前が変わったときに作り直せない。

入力の `player` は利用者の ID だけで、画面に出す名前がスクリプトに届いていなかった。

## 決定

1. **Built-in に Label を足す**。フィールドは `text`（文字列。空なら出さない）、`color`、`size`（文字の高さ、メートル）。Collider は付けないので、クリックは奥へ抜ける。描くのはクライアントだけで、実行（勝敗など）には関わらない。向きは +Z（立っている人から見て正面）。
2. **入力に `playerName` を足す**。任意で、最大 32 文字。無いクライアントからも受け取れるので、プロトコルの版は上げない。本人の確定はこれまでどおり `player` の ID で、名前は画面に出すためだけに使う（今はクライアントの申告どおり。ADR 0012）。ワークスペースとセッションは、入力を渡すときに、空なら自分の表示名を入れる。
