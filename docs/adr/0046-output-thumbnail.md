# ADR 0046：アウトプットのサムネイルと、撮るためのカメラ

- 状態：採用・実装済み（2026-11-06）
- 関連：ADR 0006（素材）、ADR 0007（作品・リリース）、ADR 0010（リソース参照と診断）

## 背景

アイテム・マーケット・プロジェクトの一覧では、名前の文字や箱の絵しか出せず、見分けにくい。アウトプットに絵を付けたい。ただ、画像を別に用意するのは手間なので、空間の中で簡単に撮れるようにしたい。

## 決定（利用者と決めたこと）

- アウトプットに**サムネイル**（`OutputDef.thumbnail`）を持たせる。Inspector（アウトプットを選んだとき）で設定する。
  - 選べるのは、**Resources にある画像**だけ。ないもの・画像でないものを指していたら、問題（診断）にする。
- サムネイルの欄に「**カメラを出す**」を付ける。
  - カメラは空間に置く物として、目の前（少し右下）に出す。
  - 右クリックで持って動かす。持ったままホイールで前後に動かせる。
  - Inspector に、カメラに映っているもののプレビューを出す。
  - 「撮ってサムネイルにする」で、640×360 の PNG にする。それを Resources のいちばん上の「**サムネイル**」フォルダ（なければ作る）に足し、サムネイルに設定する。
  - カメラ本体・選択の枠・パネルの穴・人の姿・ほかの作業の枠は、撮った画像に写さない（`userData.noShot`）。背景は空の色で塗る。
  - カメラは自分の画面にだけ出る（ほかの人には見えない）。
- 出す場所
  - アイテム（所持一覧）とマーケットのカード：リリースした版のサムネイルを出す。
  - プロジェクトの一覧：いまの版で最初にサムネイルを持つアウトプットのものを出す。
- 公開した作品のリリース版のサムネイルは、元データを見られない人にも見せる（ログインしていれば取り出せる）。ほかの素材の見せ方は変えない。

- 公式のコンテンツ（同梱の公式ライブラリ combat・interaction・items）にも、サムネイルを付ける。
  - 絵は `scripts/gen-official-thumbnails.mjs` で作る（SVG を Playwright で PNG にする）。
  - ID は repo-model（`officialThumbnails.generated.ts`）に、画像そのものはサーバー（`apps/server/src/officialThumbnails.generated.ts`）に置く。サーバーは起動時に素材置き場へ入れる。
  - サムネイルは公開した中身（content hash）に入らない。そのため、起動時の「出し直すか」は、hash に加えてサムネイルも比べる。

## 作り

- `SessionEngine.claimPointer`：ほかより先にボタンを引き受ける仕組み。照準の先がカメラなら、Entity などより先にカメラを持つ。
- `SessionEngine.renderShot`：撮影用のカメラで、手伝いの表示を隠して render target に描く。
- `ThumbnailCamera`（`apps/client/src/session/`）と `ThumbnailField`（Inspector の欄）。
