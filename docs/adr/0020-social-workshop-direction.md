# ADR 0020：3D の制作・交流とワークショップをつなぐ

- 状態: 採用（2026-11-05、体験の方向性のみ）
- 関連: [ADR 0003](0003-panels-2d-3d.md)、[ADR 0005](0005-sessions-identity-host.md)、[ADR 0007](0007-repos-commits-works.md)、[ADR 0019](0019-api-stability-all-experimental.md)
- 画面仕様: [メインメニューの UI/UX](../plans/social-workshop-experience.md)（初期版実装済み）
- 後続の判断: [ADR 0021](0021-main-menu-window.md)で、五つの画面と左上から開くウィンドウを採用。[ADR 0027](0027-main-menu-integration.md)に初期版の実装結果を集約した。

## 背景

Tukurium には制作・共同編集・試遊・公開・再利用の基盤があり、その拡張計画もある。利用者と、Tonarium のソーシャルの思想を取り入れ、作る人・遊ぶ人・見ている人が一緒に過ごす場と、作品を発見するワークショップをつなぐ方向を確認した。

## 決定

1. 3D 空間で、制作する人だけでなく、試す人や見学する人も参加できる体験を目指す。別々の作品を作りながら集まることも含める。
2. セッションでの制作・交流・試遊と、ワークショップでの作品の発見・利用・次の制作をつなぐ。ワークショップは公開作品への入口であり、新しい実行環境や保存先を導入すると決めたものではない。
3. 2D クライアントは当面の対象から外す。既存の編集パネルの 2D・3D 表示は変更しない。
4. 交流・参加・発見の体験計画を、制作ツールと UGC 基盤の計画に接続する。実装の担当範囲を分け、同じ作業を二重に管理しない。

## 最初に設計する範囲（2026-11-05 の追加指示）

最初は、セッションへの参加と、そこにいる人が分かるソーシャルメニュー、および公開アイテムを簡単に検索・取り出しできる UI/UX を設計する。音声通話や共同試遊の実装を先に進める計画にはしない。

3D クライアント内のメニューとして設計し、2D クライアントは追加しない。画面構成と操作の案を先にレビューし、データ・通信・機能実装はその後に検討する。

## 未決定のこと

音声・文字の会話、招待、フォロー、通知、作者ページなどの具体的な機能、公開範囲、検証順、実装順は未決定。詳細計画の候補を、この ADR によって採用済みとしない。

セッションの寿命、ワークスペースや作品の権限、配布・再利用の基盤を定める既存 ADR は置き換えない。これらを変える必要が出た場合は、別の判断として記録する。
