# ADR 0043：詳細パネルでも、マテリアルと素材の見た目を出す

- 状態: 採用・実装済み

## 理由

マテリアルの色・粗さ・金属感・画像は数値だけだった。テクスチャとモデルは Resources で選んでも、詳細パネルが開かず見た目がなかった。履歴の差分では変更前と変更後を並べている（ADR 0041）が、いまの素材そのものも同じように見たい。

## 決定

- マテリアルの詳細の上に、いまの色・粗さ・金属感・画像を載せた球を出す。欄を変えると、球も一緒に変わる。
- テクスチャとモデルを Resources で押すと、詳細パネルを開く。テクスチャは画像、モデルは小さな立体で出す。
- 描くのは、詳細パネルや差分の行を開いているあいだだけ。見た目の描き方は一箇所にまとめる。
