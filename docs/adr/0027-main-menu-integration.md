# ADR 0027：ホームを共通メニューへ集約する

> 単一ウィンドウの構成は [ADR 0029](0029-independent-tool-windows.md) で置き換えた。

- 状態: 採用・実装済み（2026-11-05、A7）。プロジェクト画面への移動は [ADR 0028](0028-session-and-optional-workspace.md) で置き換え。
- 関連: [ADR 0021](0021-main-menu-window.md)〜[0026](0026-session-invitations.md)

## 決定

参加前のホームと、参加中に左上から開くメニューは同じウィンドウを使う。ホームにはフレンドがいる場所、所持アイテム、マーケットの新着、セッションの作成、制作の入口をまとめる。表示するデータと操作は各画面と共有する。

五つの画面の切り替え、ウィンドウの開閉・移動・サイズ変更・2D/3D切り替えで、セッションや編集中の内容を作り直さない。検索・選択・スクロール位置を保持し、左上から呼び戻せる。タイトルバーを含むウィンドウ全体のキー入力を、空間や制作の操作へ流さない。

未参加で所持アイテムを取り出そうとした場合はセッション選択へ進み、参加できたら所持一覧へ戻る。選んだ作品を保ち、本人が改めて「取り出す」を押すまで配置しない。

制作・ライブラリ・ワールドと配置・バッグの操作を共通メニューから開けるようにする。独立したプロジェクトや探索のページへ移る操作は、参加中なら退出の確認を出す。ヘッダーの「作る」「探す」は、参加中の作業を保ったまま制作またはマーケットを開く。

## 初期版の範囲

無料で入手して版を固定する所持一覧、申請・承認型のフレンド、状態・ひとこと・招待までを対象とする。所持は利用権限を増やさず、招待は参加や編集の権限を増やさない。メニューは本人だけの画面として保持し、他者向けの制作パネルには送らない。

2Dクライアント、通話、DM、参加確認メッセージ、課金、ランキング、作者が設定するサムネイル・カテゴリ、所持する版の更新は後続で判断する。サムネイル未設定は代わりの図と説明を表示する。

## 確認

段階ごとの結果とコミットは[完了記録](../archive/main-menu-implementation.md)にまとめた。最終確認で、ホームから集まりを探し、入手・参加・取り出しを経て制作へ戻る流れを通した。タイトルバーを含む入力の分離、狭い画面、取得失敗、ページ移動の取消も確認した。

PostgreSQL 17を含む単体テスト337件、既存E2E4本、lint・型検査・ビルドが成功。本番ビルドとPostgreSQLでもセッション作成・制作・再生のスモークテストが通った。単体テストは既存の1件をスキップしている。
