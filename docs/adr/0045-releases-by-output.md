# ADR 0045：リリースは、アウトプットごとに履歴で出す

- 状態: 採用・実装済み
- 関連：ADR 0007（作品はアウトプットごとの公開の単位）

## 理由

作品もリリースも、データとしてはアウトプットごとだった。画面ではそれを縦に重ねていたので、どのアウトプットの、どのバージョンかが一覧にまとまって見えた。

## 決定

- プロジェクトの Releases は、左にアウトプット、右に選んだアウトプットのバージョンを出す。
- バージョンは新しいものから、履歴のように並べる。いちばん上が最新。
- まだ公開していないアウトプットも左に出す。選ぶと、右から作品として公開できる。
- 権限と公開タグは、選んだアウトプットの右に残す。
