# ADR 0075：Inspector の詳細の幅は境目で変え、欄の名前は同じ幅にそろえる

- 状態: 採用・実装済み
- 関連：ADR 0048（詳細の名前と KokoState）

## 理由

詳細の欄の名前は、行が幅を分けておらず、入力の側に押されて省略記号になっていた。position のような短い名前でも、ほとんど読めなかった。名前の開始位置も揃っていなかった。詳細の幅は 380px で固定で、Inspector を広げても広がるのは階層の側だけだった。

## 決定

- 階層と詳細の境をドラッグして、詳細の固定幅を変える。左右の矢印キーでも変える。Inspector を広げた分は、これまでどおり階層へ回す。パネルが狭いときは、階層が読める幅を残すところまで詳細を縮める。選んだ幅はブラウザに覚え、次に開いたときも使う。
- 欄の名前は、詳細の中で同じ幅を取る。詳細を広げると、その幅も広がる。380px のとき 104px。3つの数値が読める幅は残す。
- 名前が幅に入りきらないときは、省略せず、文字を小さくして全部入れる。
- 画面が狭くて上下に分かれるときは、境のドラッグは出さない。
