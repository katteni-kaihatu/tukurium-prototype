# ADR 0014：セッションで開くワールドは一つ

- 状態：採用（2026-11-03）
- 関連：ADR 0006（配置）、ADR 0008（ワールドは原点）、ADR 0012（最初に置いた World が土台）

## 背景

セッションに置けるものは複数ある。利用者から見ると、セッションは「どのワールドを開いているか」で決まる。公開されているワールドから選びたい。制作用の「セッションに出す」とは別の、利用者向けの操作である。

## 決定

- 画面上部の「セッション」から、公開されているワールド（最新のリリース）を選んで開く。
- 開くと、それまでセッションに置いてあったワールドはすべて外れ、選んだリリースが原点・向き 0 で一つ置かれる。
- アイテムの配置は残る。
- すでにそのリリースだけが開いているときは、何もしない（実行状態は戻さない）。
- 開けるのは、作品の「利用」権限がある人か、作品の持ち主。セッションの持ち主である必要はない。
- アイテムのリリースは開けない。
- ワークスペースからの「セッションに出す」は、これまでどおり追加で置ける。利用者がワールドを開いたとき、その配置も外れる。

## 制約

- 開いたあとの実行状態は、新しいワールドの初期値から始まる。前のワールドの状態は残さない。
- 同じセッションにワールドを複数「セッションに出す」ことは、この操作をするまではできる。土台は、置いた順の最初のワールド（ADR 0012）のまま。
