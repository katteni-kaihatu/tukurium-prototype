# ADR 0036：ステータスを共通ウィンドウで開く

- 状態: 採用・実装済み（2026-11-05）
- 変更: [ADR 0035](0035-friend-status-dialog.md) の専用ダイアログ

## 理由

ステータスだけが固定表示のダイアログになり、ほかのウィンドウと同じように持ったり、空間へ置いたりできなかった。利用者の操作をそろえるため、共通のウィンドウとして扱う。

## 決定

ステータスも `MainMenuHost` のウィンドウ一覧に登録し、`PanelLayer` で表示する。移動、サイズ変更、前後関係、2D/3Dの切り替え、呼び戻し、Escと閉じるボタンは共通の処理を使う。ステータス専用の移動処理とモーダルの背景は設けない。

「ステータスを変更」から開き、フレンドのウィンドウと独立して使える。ほかの窓を操作しても入力中の内容を保つ。ステータスの窓を閉じるかキャンセルすると、未保存の入力を捨てる。「設定する」で保存するまで、フレンドに見える状態は変えない。

状態の4択、32文字の入力欄、プレビュー、既存の長いひとことへの対応はADR 0035を引き継ぐ。
