# ADR 0064：ホームとフレンドのウィンドウの中身を、トナリウムの見た目に寄せる

- 状態: 採用・実装済み（2026-11-10）
- 継続: [ADR 0029](0029-independent-tool-windows.md) の独立したウィンドウ（ページにはしない）、[ADR 0027](0027-main-menu-integration.md) のホームの中身

## 背景

UI をトナリウムに寄せる段階 4。統合案（U1・U2）では、ホームとフレンドが左右の欄の間のページになっている。利用者と相談して、ウィンドウのまま中身の見た目だけを寄せることにした。

## 決定

1. ホームの「フレンドがいるセッション」を「フレンドの今」にする。
   - フレンドが多いセッションから順に、色の帯のついたカードで並べる
   - カードの帯に人数と「参加する」を置く
   - 本文を押すと、セッションのウィンドウでそのセッションを選ぶ
2. ホームの本文に「オンラインのフレンド」を置く。並べるのは、オンラインでセッションにいないフレンド。
   - 顔・状態の丸・ステータスとひとことを出す
   - 「誘う」は、フレンドのウィンドウでその人を選ぶ（招待はそこから送る）
   - メッセージのボタンは、ボタンだけ置く
3. フレンドのウィンドウ
   - 表示の切り替え（すべて・フレンドの今・フォロワー・フォロー中・ブロック中）を置く。使えるのは「すべて」だけで、ほかはボタンだけ
   - 一覧は、顔と状態の丸がついたカードにする
   - 詳細の下に、メッセージの入力欄と送信のボタンを置く。仕組みがないので、入力欄は無効にする
4. 所持アイテム、マーケットの新着、セッションを作る、制作するは、これまでどおり残す。

## この記録で決めないこと

ホームの検索、最近さわったプロジェクト（つづきを作る）、フォローとブロックの仕組みは決めない。
