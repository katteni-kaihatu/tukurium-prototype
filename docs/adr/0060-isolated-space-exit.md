# ADR 0060：独立した空間に、セッションへ戻る出口を置く

- 状態: 採用・実装済み
- 関連：ADR 0008（権限・プライベートな作業・ワールドの編集）。0008 の「区画にポータルを置く」に、戻る出口を足す

## 理由

ワールドの編集と非公開の作業は、セッションから離した空間で行う。区画のポータルからは入れるが、空間の中に戻る口がなかった。パネルの「セッションに戻る」を開いていないと、歩いては出られなかった。

## 決定

- 独立した空間の中に、緑の出口を置く。くぐると、そのワークスペースの区画（セッション）へ戻る。入り口の紫のポータルは、これまでどおり区画に置く。
- 出口は、ポータルで着いた位置（目的地の +Z 側 6m）から、さらに 3.5m 奥。ポータルの届く距離（1.2m）より遠いので、着いた直後には入らない。後ろへ下がると届く。
- 戻ったあとは区画の手前（+Z 側 6m）に立つ。入り口（z = −3）までは 9m あり、戻った直後にまた入らない。
- 一つのフレームでは、一つのポータルしか使わない。
- 出口を出す相手は、入り口と同じ。閲覧できる人には、開いていなくても出口がある。閲覧できない人には入り口も出口もない。
- 通信の形は変えない。出口の位置は、独立した空間の置き場所から各画面が計算する。

## 影響

- パネルの「編集空間へ」「セッションに戻る」も、これまでどおり使える。
