# ADR 0031：上のセッションバーに、左の補助アイコン列をつなぐ

- 状態: 採用・実装済み（2026-11-05）。バーとの接続表示は [ADR 0032](0032-navigation-island-labels.md) で変更。
- 変更: [ADR 0029](0029-independent-tool-windows.md) の入口の置き方
- 継続: [ADR 0030](0030-workspace-switcher-display.md) のワークスペース表示、各機能の独立ウィンドウ

## 決定

上のバーを主な表示として、今いるセッションの名前・人数・参加者、ワークスペース、セッション、バッグ、退出の操作をまとめる。ワークスペースは名前と数が見える旧表示を維持する。

フレンド・セッション・アイテム・マーケット・プロジェクト・ライブラリは、セッションに入る前から使うアプリ全体の機能として左に縦並びで置く。左は上のバーの左下につながる補助アイコン列とし、別の大きなサイドバーにはしない。各アイコンは機能名を読み上げられ、カーソルを重ねても名前が分かる。

ライブラリはワークスペースのパネル一覧から独立させ、セッション未参加でも閲覧できる。セッションに置く操作は参加後に使える。編集中なら、これまでどおりプロジェクトへライブラリを追加できる。

## 表示と操作

- 上のバーは画面幅いっぱいに置く。ホームへの入口と接続状態もここに残す。
- 左のアイコンは幅を抑え、上のバーの高さに合わせて追従する。狭い画面でも省略しない。
- ウィンドウの初期位置と呼び戻し先は、上のバーと左のアイコンに重ならない範囲に収める。
- 各ウィンドウの同時表示・検索・下書き・2D/3D配置は維持する。表示変更でセッションやワークスペースを作り直さない。
