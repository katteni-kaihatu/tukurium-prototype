# ADR 0033：デフォルトの床を暗いグリッドにする

- 状態: 採用・実装済み（2026-11-05）

## 理由

明るい床と薄い線では、床の位置や奥行きが分かりにくい。利用者が提示した Resonite の GridSpace の画像を参考に、距離と大きさをつかみやすい床にする。

## 決定

デフォルトの床は青みのある暗いグレーとし、20 cm 間隔の細線と 1 m 間隔の区切りを重ねる。細線は近くで見せ、遠くでは徐々に消す。画面上で線が細かく重なる場所でも薄くし、ちらつきを抑える。

床はこれまでどおり物の影を受ける。空やアイテムの照明、床の高さ、移動と衝突の扱いは変えない。
