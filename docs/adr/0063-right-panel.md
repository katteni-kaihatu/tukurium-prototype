# ADR 0063：右の欄に「フレンドの今」・通知・チャットと通話の操作を置く

- 状態: 採用・実装済み（2026-11-10）
- 継続: [ADR 0062](0062-session-tag-and-sidebar.md) の左の欄、[ADR 0026](0026-session-invitations.md) の招待

## 背景

UI をトナリウムに寄せる段階 3。統合案では、画面の右に通知とコミュニケーションの欄を置く。いまのツクリウムにはチャット・DM・通話がない。

## 決定

1. 画面の右に、上下 16px・幅 300px の欄を置く。重なり順はウィンドウより下にし、ウィンドウを上に重ねられるようにする。
2. 参加前は「フレンドの今」（フレンドがいるセッション）と通知を出す。行を押すと、セッションのウィンドウでそのセッションを選ぶ。見出しの切り替え（▾）はボタンだけ置く。
3. セッション内は、通知・チャット・通話の操作を出す。
4. 通知には、届いている招待とフレンド申請を出す。招待の「参加」は、これまでの「受け取って参加先を見る」と同じ処理にする。申請の「見る」は、フレンドのウィンドウを開く。
5. チャット・メッセージ・ログのタブ、声の範囲、送信、マイク・サウンドボード・音量は、仕組みがないのでボタンだけ置く。入力欄は使えないことが分かるよう、無効にして「チャットはまだ使えません」と出す。
6. 右の欄はたためる。たたむと、開くボタン・通知（届いていれば赤い丸）・チャット・マイクの列になる。制作を始めたらたたみ、幅 1100px 以下ではたたんで始める。

## この記録で決めないこと

チャット・DM・通話の仕組み、通知の既読、ログ（セッションの出来事の記録）の中身は決めない。
