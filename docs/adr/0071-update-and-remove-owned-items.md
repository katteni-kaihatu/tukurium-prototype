# ADR 0071：所持アイテムをアップデートし、消せるようにする

- 状態: 採用・実装済み（2026-11-13）
- 関連: [ADR 0024](0024-owned-items-and-placement.md)、[ADR 0034](0034-owned-item-tags-and-browsing.md)

## 背景

所持アイテムは入手したときの版のまま残り、作者が新しい版を出しても替える手段がなかった。いらなくなったアイテムを一覧から外す手段もなかった。

## 判断

- **アップデート**：`PUT /api/me/items/:workId` に `releaseId` を渡すと、所持している版を替える。入手と同じく、その作品のアイテムのリリースで、利用できるものに限る。所持していない作品は 404。入手日は変えない（入手した順の並びを保つ）。
- 画面では、作品の最新の版が所持している版より新しく、利用できるときだけ、カードに「vN あり」の印を付け、詳細に「vN にアップデート」を出す。自動では替えない。
- **消す**：`DELETE /api/me/items/:workId` で所持一覧から消す。所持していなくても成功を返す。利用できなくなったアイテムも消せる。詳細の「所持アイテムから消す」から、確認してから消す。
- 消しても、アップデートしても、セッションに出している配置には触れない。配置は取り出したときの版のまま残る。消したアイテムは、マーケットからまた入手できる。
- お気に入りなどブラウザに保存した整理情報は消さない。また入手したときに戻る。

ADR 0024 の「同じ作品の再入手で版を上書きしない」はそのまま保つ。版を替えるのは、入手とは別の、本人のはっきりした操作にする。

## 確認

MemoryStore で版の差し替え・未所持の差し替え・削除を、PostgreSQL では接続し直した後の保持と削除を検査する（`TEST_DATABASE_URL` があるとき）。API では、本人以外・別の作品のリリース・利用できない作品へのアップデートの拒否、入手日の保持、利用できない所持品の削除、未ログインの拒否を検査した。画面は開発サーバーで、印・アップデート・消す確認と一覧からの消去をスクリーンショットで確かめた。
