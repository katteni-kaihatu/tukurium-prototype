# ADR 0038：編集用データがある既存先への抽出を拒否する

- 状態: 採用・実装済み
- 関連: [Issue #62](https://github.com/katteni-kaihatu/tukurium-prototype/issues/62)

## 理由

抽出はGitへ取り込む一方、編集画面は保存済みY.Docを開く。そのため、以前編集したプロジェクトへ抽出すると、次の編集コミットで取り込み内容が消えていた。実際のAPI、ワークスペースを開く処理、編集コミットを通して再現した。

## 決定

取り込み先にワークスペースの記録または保存済みY.Docがある場合、既存先への抽出は409で拒否する。Gitと編集用データを変更せず、新しいプロジェクトへ抽出するよう案内する。編集中の未コミット変更を上書きする同期処理は、今回追加しない。

新しいプロジェクトへの抽出と、まだ編集を開始していない既存先への抽出は維持する。同じリポジトリへの抽出とワークスペースを開く操作は順番に処理し、検査中に編集を開始して古いデータを開くことも防ぐ。
