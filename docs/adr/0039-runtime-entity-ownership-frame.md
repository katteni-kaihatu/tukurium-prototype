# ADR 0039：生成物の所属を実行フレームで引き継ぐ

- 状態: 採用・実装済み
- 関連: [Issue #64](https://github.com/katteni-kaihatu/tukurium-prototype/issues/64)

## 理由

WorldのEntityは復元されても、実行中に生成されたEntityがどの配置のものかは失われていた。その結果、Systemの処理対象から外れ、配置の削除やリセットでも残っていた。実際のSimulationで生成物を一つ作り、引き継ぐ手順で再現した。

## 決定

ワークスペースとセッションの実行フレームに、配置ごとのEntity一覧を `partEntities` として含める。Simulationの復元時にこの一覧も戻し、存在するEntityだけを所属させる。生成物のIDやWorldの保存形式は変えない。

新しい情報を持たないフレームは引き続き読み込める。その場合、制作データから分かる所属を使う。過去のフレームで失われた生成物の所属は推定しない。バッグの引き継ぎは既存の処理を維持する。

追加フィールドは任意とし、通信プロトコルの番号は変えない。ホストの引き継ぎで所属を保つには、新しいフレームを送るクライアントと受けるクライアントの双方がこの実装を使う。
