# Tukuriumの構想・設計

Tukuriumは、作品を作る人と遊ぶ人が同じ3D空間にいて、共同制作を試すプロトタイプ。自分や少人数で、作る・試す・組み合わせて遊ぶ・改造する流れを快適に試せることを目指す。

ここには、目指す体験、そのための大きな仕組みと役割分担、そう考える理由を残す。実装と試作から得た知見を含む、構想・設計の成果物である。

## 対象と範囲

ココバースの制作・共同作業を、Tukuriumで試す範囲を中心に表す。Tonariumの、人と集まって過ごす考え方を取り入れ、作る人・遊ぶ人・見ている人が一緒に過ごせる場を目指す。現在の接点はフレンド・状態の共有・招待。通話やDMなど、交流機能をどこまで広げるかは未決定。関連する判断は[制作・交流とワークショップ](../adr/0020-social-workshop-direction.md)へ。

対象は、作品の作り方、人が集まって遊ぶ仕組み、制作と遊びのつながり、作品を共有・再利用する考え方。複数の機能に関わる前提や、利用者にとって意味のある振る舞いを説明する。

個々の画面操作、APIの一覧、内部の実装手順、作業予定や不具合の一覧は、それぞれの資料・コード・Issueが受け持つ。画面の配色や部品の基準は[UIデザイン](../../design.md)へ。試作の結果は、大きな考え方に影響する知見として残る。

制作中の作品をその場で試し、適用して遊びへ反映し、公開した版をほかの人が再利用する。この往復が各領域をつないでいる。

制作と遊びはつながっている。例えば、編集の適用は制作側で説明し、遊び側から参照する。資料の区分は説明の居場所であり、実装の分割や用語のタグと一対一には対応しない。
