# 用語

Tukurium で使う言葉の意味と呼び方。新しく文章を書くときは「呼び方」の列を使う。「別の呼び方」は、既存の資料やコードを読むために残す。コード上の名前や、技術一般の言葉まで一律に言い換えるものではない。

## 作る

| 呼び方 | 別の呼び方 | 意味 |
| --- | --- | --- |
| プロジェクト | リポジトリ、Repo | 制作データと履歴をまとめて残す単位。Git での保存を説明するときは「リポジトリ」を使う。 |
| ワークスペース | Workspace | プロジェクトを開き、複数人で編集・試し再生する作業場所。 |
| 出力 | アウトプット、Output | プロジェクトの一部を、アイテム・ワールド・ライブラリとして使うまとまり。一つのプロジェクトから複数作れる。 |
| 制作データ | — | 形・コード・初期値など、作者が編集して残すもの。 |
| 実行状態 | — | 今の位置や残弾など、動かしている間に変わるもの。制作データとは分ける。 |
| 試し再生 | — | ワークスペースで作品を動かして試すこと。セッションでの遊びとは独立している。 |
| 適用 | Apply | ワークスペースの変更を、セッションに置いた配置へ反映すること。編集しただけでは反映しない。 |
| コミット | — | 作業の区切りとして履歴に残すこと。公開する版の元になる。 |

## 遊ぶ

| 呼び方 | 別の呼び方 | 意味 |
| --- | --- | --- |
| セッション | インスタンス、部屋、Session | 人が集まり、作品を作ったり組み合わせて遊んだりする場所。 |
| 配置 | Placement | アイテムやワールドの出力をセッションに置いた実体。同じ出力から複数作れる。 |
| 所持アイテム | 所持品 | 入手したアイテムと版の記録。セッションに置いた実体とは区別する。所持しても利用の権限は増えない。 |
| ホスト | 実行役、Host | 作品の処理を動かし、参加者へ状態を送る役。 |

「インスタンス」は個々の実体を指すこともあるので、セッションの意味では「セッション」を使う。

## 公開・再利用

| 呼び方 | 別の呼び方 | 意味 |
| --- | --- | --- |
| 公開作品 | 作品（公開の文脈）、Work | 出力を公開する単位。制作物全般を指す「作品」と区別するときに使う。 |
| リリース | Release | 公開作品の、特定のコミットに結び付いた版。 |
| マーケット | Market | 公開作品を探して入手する入口。 |
| ライブラリ | Library | ほかの制作で使う定義や処理をまとめた出力。セッションに置かず、依存として使う。 |
| 依存 | Dependency | プロジェクトやライブラリが使う別のライブラリ。版と中身を固定して参照する。 |
| Package | パッケージ | 配布する部品の出所と版を扱う単位。 |
| フォーク | Fork | プロジェクトを履歴と由来ごと複製して改造すること。 |
| 抽出 | Extract | 選んだ出力やリソースを、必要なものと一緒に別のプロジェクトへ取り込むこと。 |
| 由来 | — | 取り込んだものや複製したものが、どの作品から来たかの記録。 |

## 作品の仕組み

| 呼び方 | 別の呼び方 | 意味 |
| --- | --- | --- |
| EKS | ECS | Entity / KokoState / System で作品を作る方式。ECS の Component を KokoState と呼び替えたもので、別の方式ではない。 |
| Entity | エンティティ | 的や扉など、作品の中の一つの要素。 |
| KokoState | ECS の Component | 位置や体力など、要素が持つ状態。UI 部品などを指す Component とは区別する。 |
| System | — | どの状態を持つかで対象を選び、動かす処理。 |
| イベント | Event | 押した・当たったなど、一度の出来事。続く状態は KokoState で扱う。 |
| Contract | 公開操作 | 作品が外へ公開する操作の型。受け手が処理を決める。 |
| Capability | — | 作品がホストの機能を使うための許可。 |
| Host API | ホスト API | 物理や音など、基盤の機能をスクリプトから呼ぶための入口。 |
| 実行領域 | realm | スクリプトが動く領域。出所や版ごとに分け、別の版のコードが混ざらないようにする。 |
