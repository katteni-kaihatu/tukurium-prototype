# KokoStateに型付きのレコード・リスト・マップを持てる

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

KokoState の欄に、数や文字や `vec3` だけでなく、型の決まったレコード（いくつかの欄の組）・リスト・マップを持てる。Inspector と System の両方で扱え、入れ子の値も型を確かめたうえで保存・復元できる。

## 原則とのつながり

- 原則 2（入口は低く、奥は深い）：盤面・手札・持ち物のようなまとまったデータを、欄を並べる工夫なしに作れる。
- 原則 5（安心して作れる）：入れ子の値も型で確かめるので、壊れた値が保存されない。

## やること

- 欄の型に、レコード・リスト・マップを足す。入れ子にできる。
- Inspector で、入れ子の値を見て・足して・消して・並べ替えて・直せる。
- System から、型の付いた値として読み書きできる（ロードマップの「スクリプトをすべてTypeScriptで書く」の型に載る）。
- 保存・復元のときに、入れ子の値の型を確かめる。合わない値は問題として出す。
