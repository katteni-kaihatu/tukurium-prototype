# プレハブの一部を上書きしてバリアントを作る

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

プレハブの一部を上書きして、バリアント（派生）を作れる。たとえば「的」から「固い的」を作る。バリアントも独立したリソースで、元のプレハブへの参照と、上書きした差分を持つ。上書きしていない所には、元の変更が届く。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）：少しだけ違うものを、複製せずに作れる。元を直せば、派生にも届く。

## やること

- プレハブのフィールドの値・KokoState・子の Entity を上書きして、バリアントを作る。
- バリアントは独立したリソースで、元への参照と差分を持つ。プレハブと同じように置いて、インスタンスを作れる。
- 上書きしていない所には、元の変更が届く。
- 元を直して上書き先が消えた（フィールドや子がなくなった）ときは、Inspector で分かるようにする。
