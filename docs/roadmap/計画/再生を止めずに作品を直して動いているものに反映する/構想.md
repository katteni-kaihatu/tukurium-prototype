# 再生を止めずに作品を直して動いているものに反映する

- 状態：作成中（たたき台）
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

ワークスペースで再生したまま、作品を直せる。直したことは、止めずに、動いているものに反映される。

今は、再生中（Play mode）には編集できない。直すには、止めて、直して、また再生する必要がある。止めずに直せれば、動きを見ながら少しずつ整えられる。

例：

- 的の大きさを直すと、動いている的がその場で大きくなる。
- プレハブを直すと、実行中のインスタンスにも反映される。
- スクリプトを直すと、次のフレームから新しいスクリプトで動く。

## 原則とのつながり

- 原則 1（作る場所と遊ぶ場所が同じ）：遊びながら、そのまま作り直せる。
- 原則 2（入口は低く、奥は深い）：止めて直して再生し直す手間なしに、動きを見ながら試せる。

## やること（たたき台）

- 再生中も、Hierarchy・Inspector・エディタで編集できる。
- 直したことを、動いているものに反映する。
  - フィールドの初期値：動いている値を、新しい初期値に置き換えるか、置き換えないかを決める（「維持」の考え方と合わせる）。
  - Entity を足す・消す：動いている World にも足す・消す。
  - KokoState を付ける・外す：動いている Entity にも付ける・外す。
  - プレハブ：実行中のインスタンスにも反映する。
  - スクリプト：次のフレームから、新しいスクリプトで動かす。
- 一緒に作っている人にも、同じように反映される。

## やらないこと（たたき台）

- セッションに出した配置に、すぐ反映すること（今と同じく「適用」で届ける）。

## 完了の条件

未定。

## 決まっていること・決まっていないこと

- 決まっていること：
  - プレハブを変えたら、実行中のインスタンスにも反映する（計画者と決めたこと）。
- 設計者・実装者に任せること：未定。
- 計画者に聞くこと：
  - 直したフィールドの初期値を、動いている値に反映するか。反映するなら、どの値を引き継ぐか（「維持」を付けたフィールドは引き継ぐ、など）。
  - 再生中に直したことは、止めたあとも残るか（今の「Play mode 中の出来事はプロジェクトに残りません」との分け方）。
  - スクリプトを直したとき、動いている System の状態をどう扱うか。
  - 再生中に、だれが直せるか（再生を操作できる人と同じか）。

## 関係するもの

- ロードマップの「Systemの可変データを次の呼び出しに持ち越さない」（スクリプトを直して読み込み直しても、状態が KokoState にあれば失われない）
- ロードマップの「デバッグ実行で一時停止して確かめながら原因を探す」（一時停止中に値を変えて続ける）
- ロードマップの「プレハブを作ってインスタンスをアウトプットに置く」（完了。今は再生中にプレハブを編集できない）
- ADR 0076（プレハブとインスタンス）
