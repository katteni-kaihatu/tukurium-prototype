# 利用者が作ったライブラリを配って選んで使える

- 状態：作成中（見直す予定）
- 計画者：れにうむ
- 作成完了日：（作成中。元の計画は 2026-11-05）

## やりたいこと

利用者が作ったライブラリを公開し、ほかの人が探して導入し、バージョンを選んで使い、明示的に更新できる。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）
- 原則 3（作品を通じて一緒に作れる）：誰の作品から来たかが分かる。

## やること

もとの計画（UGC API・権限・Library Package の U6）から移した内容。基盤を実測したあとに広げる。

- 公開・検索・導入・フォーク・バージョンの一覧
- 発行者の確かめと、公式の認証
- ライセンス・由来・依存の表示
- サーバーでの manifest と content hash の確かめ
- 書き換えないリリースと、明示的な更新

公開アイテムの検索・入手、所持一覧からの取り出し、参加先を選ぶ画面はすでにある。リリースとバージョンを同じ正本として使う。ライブラリの配布・導入・更新は、それとは別の操作として扱う。

## やらないこと

- ランキング・評価・収益化・自動推薦（別に判断する）
