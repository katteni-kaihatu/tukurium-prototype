# 型を指定してKokoStateのテンプレートを使う

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

型を後から決められる KokoState のテンプレートを使える。たとえば `Deck<T>` から `PlayingCardDeck`（トランプの山札）のような具体的な定義を作り、複数の Entity と System で使い回せる。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）：山札や持ち物のような形を、中身の型を変えて何度も使える。

## やること

- 型の引数を持つ KokoState のテンプレート（例：`Deck<T>`）を作れる。
- 型を指定して、具体的な定義（例：`PlayingCardDeck`）を作る。作った定義は、ふつうの KokoState と同じく、複数の Entity と System で使える。
- Inspector から型を選んで作ったときも、確定した定義をプロジェクトに残す。

  - 呼び方。プロジェクトを作るときの「テンプレート」と紛れるので、別の呼び方にするか。
