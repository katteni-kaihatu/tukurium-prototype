# 抽出やフォークのあとも参照と由来を保つ

- 状態：作成中（見直す予定）
- 計画者：れにうむ
- 作成完了日：（作成中。元の計画は 2026-11-05）

## やりたいこと

制作データの結び付けを保存できるようにし、抽出やフォークで ID を付け直しても、参照と由来が保たれる。

## 原則とのつながり

- 原則 3（作品を通じて一緒に作れる）：抽出・フォークしたあとも、参照と、誰の作品から来たかが保たれる。
- 原則 5（安心して作れる）：解決できない参照を、勝手に別のものへ結び付けない。

## やること

もとの計画（リソースパス・System 参照・全体診断の Phase 7）から移した内容。

- `ProjectSnapshot.version = 2`
- resource bindings / language / apiVersion を保存できるようにする。
- v1 の裸の KokoState 名を、今の registry の規則で一度だけ解決する。
- 解決できない・動的な Query は移行の問題として出し、勝手に別のものへ結び付けない。
- 抽出は依存グラフで、必要なものの範囲を求める。
- ID を付け直したあと、結び付けを直し、新しい置き場所から相対パスを作り直す。
- 由来に、名前だけでなく元のリポジトリ・リソースの ID・コミットを残す。
