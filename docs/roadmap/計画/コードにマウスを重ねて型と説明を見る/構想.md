# コードにマウスを重ねて型と説明を見る

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

スクリプトのエディタで、変数・式・関数・KokoState の欄にマウスを重ねると、その型と説明が小さな枠（ツールチップ）に出る。VS Code のホバー（TypeScript では「Quick Info」と呼ぶもの）と同じ体験にする。

たとえば `const g = e.get(Gun)` の `g` に重ねると `{ ammo: number; ... }` が、`world.spawn` に重ねると引数と説明が見える。何が入っているかを、動かしたり宣言を探したりせずに確かめられる。

## 原則とのつながり

- 原則 2（入口は低く、奥は深い）：慣れていない人も、その場で「これは何か」が分かる。慣れた人は、型をたどって深く書ける。
- 原則 5（安心して作れる）：思っていた型と違うことに、動かす前に気づける。

## やること

- スクリプトのエディタで、マウスを重ねた所の型と説明を出す。対象は、変数・引数・式・関数（Host API を含む）・import した KokoState とその欄。
- 説明は、Host API の説明（`HOST_API_SPEC` の利用者向けの説明）を出す。
- 型の誤りがある所に重ねたときは、型と一緒に誤りの文も出す（今の下線の文と同じもの）。
- 画面に出したパネルでも、空間に置いたパネルでも出る。
- 型を確かめるのと同じ、ブラウザの裏側（Worker）の TypeScript を使う。画面の本体は大きくしない。

## やらないこと

- 型の情報をもとにした入力補完の作り直し（今の Host API と import の補完のまま）。
- 定義へ移動・参照を探す・名前の一括変更などの、ほかのエディタの機能。
- スクリプト以外（KokoState の定義の画面・Inspector の欄）での型の表示。

## 完了の条件

- 同梱サンプルのスクリプトで、変数・Host API・KokoState の欄に重ねると、型と説明が日本語の画面の中で読める形で出る。
- 空間に置いたパネルでも、重ねた文字の所に出る。
- 複数人で同じスクリプトを編集している最中でも、古い内容の型を出さない。
- 型の確かめを一度もしていない状態から重ねても、待てば出る（初めの読み込みの間は「読み込み中」などと分かる）。

## 決まっていること・決まっていないこと

- 決まっていること：ロードマップの「スクリプトをすべてTypeScriptで書く」で入れた TypeScript（Worker で動く Language Service）を使う。
- 設計者・実装者に任せること：枠の見た目、出るまでの待ち時間、型の書き方を日本語の画面向けに整えるか（TypeScript の表記のまま出すか）。
- 計画者に聞くこと：
  1. 入力補完も TypeScript の型をもとにしたもの（`e.get(Gun).` のあとに欄の候補が出るなど）にするか。する場合、この項目に入れるか、別の項目にするか。
  2. 定義へ移動（`Gun` から KokoState の定義を開く）も入れるか。
  3. AI エージェントにも、同じ情報を取り出す道具（ある場所の型を聞く）を渡すか。
  4. 型の表記は TypeScript のまま（`number`、`string | null` など）でよいか。
  5. KokoState とその欄に、作者が説明を書けるようにして、重ねたときに出すか（今は説明を書く場所がない）。
