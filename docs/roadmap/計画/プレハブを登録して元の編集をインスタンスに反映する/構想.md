# プレハブを登録して元の編集をインスタンスに反映する

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

Entity と KokoState のまとまりを、プレハブとしてリソースに登録できる。プレハブは安定したリソース ID で参照して置く。プレハブを置いたものをインスタンスと呼ぶ。元のプレハブを直すと、その直しがインスタンスに届く。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）：一度作った的や駒を、何個でも置き、まとめて直せる。

## やること

- Entity（子を含む）と KokoState のまとまりを、プレハブとしてリソースに登録する。
- プレハブを、リソース ID で参照して置き、インスタンスを作る。名前や置き場所を変えても参照は切れない。
- 同じプロジェクトでは、元のプレハブの編集が、すべてのインスタンスに届く。
- 公開されたライブラリのプレハブは、利用者が選んだバージョンを参照する。バージョンを上げるまで、元の変更は届かない。

## やらないこと

- プレハブの一部を上書きすること（ロードマップの「プレハブの一部を上書きしてバリアントを作る」で扱う）。

## 決まっていること・決まっていないこと

- 決まっていること：
- 設計者・実装者に任せること：
- 計画者に聞くこと：
  - インスタンスで、場所・向き・大きさ以外を変えたいときはどうするか（この項目では変えられないとするか）。
  - インスタンスを、ふつうの Entity に戻す（つながりを切る）操作を入れるか。
  - プレハブを消したとき、インスタンスをどうするか。
  - プレハブにスクリプト（System）も含めるか。
