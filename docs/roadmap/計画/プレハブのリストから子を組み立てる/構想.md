# プレハブのリストから子を組み立てる

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

プレハブのリストから、Entity の子を組み立てられる。チェスの駒や合法手のガイドのように、数や中身が状態で変わる子を、一つずつ置かずに作れる。

## 原則とのつながり

- 原則 2（入口は低く、奥は深い）：盤面やリストの表示を、短い決まりで組み立てられる。
- 原則 4（一度作ったものを、何度でも、誰とでも使える）：駒などのプレハブを、リストで何度も使える。

## やること

二つの段階で進める。

1. **固定のリスト**：プレハブやバリアントの参照・置く場所と向きと大きさ・型の付いた引数を持つリストを使えるようにする。
2. **状態から作るリスト**：KokoState から表示用のリストを作り、安定したキーで子を足す・直す・消す。チェスの駒と合法手のガイドは、この段階で作れる。

## やらないこと

- 入れ子の構成まで状態から組み立てる仕組み（仮想ツリー）。平らなリストで足りない用途が出たら、別に検討する。

## 決まっていること・決まっていないこと

- 決まっていること：固定のリストを先に作り、状態から作るリストをそのあとに作る。
- 設計者・実装者に任せること：
- 計画者に聞くこと：
  - 「型の付いた引数」は、プレハブのどこに渡すか（KokoState の欄の初期値か）。
  - 状態から作った子を、Inspector で直接直せるか（見るだけか）。
  - 状態から作った子は、保存するか、毎回作り直すか。
