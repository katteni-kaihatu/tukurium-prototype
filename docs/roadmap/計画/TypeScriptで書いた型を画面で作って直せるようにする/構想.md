# TypeScriptで書いた型を画面で作って直せるようにする

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

KokoState のフィールドの込み入った型（レコード・リスト・マップ・選択肢・入れ子など）を、TypeScript で書かずに Inspector の画面で作れる。その型の値も、型に合った専用の画面で直せる。

## 原則とのつながり

- 原則 2（入口は低く、奥は深い）：TypeScript を知らない人も、込み入ったデータを作れる。

## やること

- フィールドの型を、画面で組み立てる（レコードのフィールドを足す、リストやマップにする、選択肢を並べる、など）。組み立てた型は、TypeScript の型として持つ。
- 込み入った型の値を、型に合った専用の画面で直す（例：レコードは入れ子のフォーム、リストは並べ替えのできる一覧、マップはキーと値の表）。
- 画面で作れる型と、専用の画面で直せる型を、少しずつ増やしていく。

- 決まっていること：型そのものは TypeScript の型として持つ（画面は、それを作って直す手段）。
