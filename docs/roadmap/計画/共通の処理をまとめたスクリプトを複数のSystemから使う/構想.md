# 共通の処理をまとめたスクリプトを複数のSystemから使う

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

System 以外に、共通の関数などをまとめたスクリプトのファイルを作り、複数の System から import して使える。同じ処理を System ごとに書かなくて済む。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）：同じ処理を何度も書かなくて済む。
- 原則 2（入口は低く、奥は深い）：大きな作品でも、処理を分けて整理できる。
