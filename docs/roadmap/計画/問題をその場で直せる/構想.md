# 問題をその場で直せる

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

問題の一覧に出た問題を、その場で直せる。直し方が一つに決まる問題は、ボタン一つで直せる。直し方が選べる問題は、候補を見て選んで直せる。

## 原則とのつながり

- 原則 2（入口は低く、奥は深い）：慣れていない人も、問題の意味や直し方を調べずに先へ進める。
- 原則 5（安心して作れる）：壊れたものをすぐ元に戻せる。

## やること

未定（構想を書くときに決める）。もとの計画（リソースパス・System 参照・全体診断の §9）にあった初めの候補は次のとおり。

- 名前を変えたり動かしたりしたものへの import のパスを、今の場所に合わせて直す
- 見つからないマテリアルや素材の指定を外す
- アウトプットから、なくなった System を外す
- 指す先のない状態維持マークを外す
- 候補が一つに決まる、解決できないパスを直す

もとの計画にあった決まりの案：閲覧だけの人は直せない。編集前の結果の問題は、確かめ直してから直す。問題を見たときと制作データが変わっていたら直さない。一つの直し方は一回の変更にまとめる。安全でない直し方は、確認してから直す。
