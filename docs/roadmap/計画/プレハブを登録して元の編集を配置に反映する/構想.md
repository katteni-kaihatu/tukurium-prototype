# プレハブを登録して元の編集を配置に反映する

- 状態：作成中
- 計画者：れにうむ
- 作成完了日：

## やりたいこと

Entity と KokoState のまとまりを、プレハブとしてリソースに登録できる。プレハブは安定したリソース ID で参照して配置する。元のプレハブを直すと、その直しが配置した所に届く。

## 原則とのつながり

- 原則 4（一度作ったものを、何度でも、誰とでも使える）：一度作った的や駒を、何個でも置き、まとめて直せる。

## やること

- Entity（子を含む）と KokoState のまとまりを、プレハブとしてリソースに登録する。
- プレハブを、リソース ID で参照して配置する。名前や置き場所を変えても参照は切れない。
- 同じプロジェクトでは、元のプレハブの編集が、すべての配置に届く。
- 公開されたライブラリのプレハブは、利用者が選んだ版を参照する。版を上げるまで、元の変更は届かない。

## やらないこと

- プレハブの一部を上書きすること（ロードマップの「プレハブの一部を上書きしてバリアントを作る」で扱う）。

未定。

## 決まっていること・決まっていないこと

- 決まっていること：
- 設計者・実装者に任せること：
- 計画者に聞くこと：
  - 配置した所で、位置や向き以外を変えたいときはどうするか（この項目では変えられないとするか）。
  - 配置したプレハブを、ふつうの Entity に戻す（つながりを切る）操作を入れるか。
  - プレハブを消したとき、配置した所をどうするか。
  - プレハブにスクリプト（System）も含めるか。
